## 已优化参数

|------|-----|------|
| min_mom_20d | -1.25 | 20日动量下限 |

| stop_loss_pct | -0.10 | 固定止损 (-10%) |
| take_profit_pct | 0.30 | 固定止盈 (+30%) |
| trailing_stop_pct | -0.09 | 移动止损回撤 (-9%) |
| trailing_stop_trigger | 0.15 | 移动止损触发 (+15%) |
| time_stop_days | 20 | 时间止损 (20日) |

## 使用方法

```bash
cd /home/taotao/.cursor/worktrees/TRQuant/ope

```

### 2. 单独测试

```python
from core.research import (
    ResearchDataProvider,
    FactorCalculator,
    SignalEngine,
    SignalParams,
    VBTBacktest,
)

# 获取数据
provider = ResearchDataProvider(use_cache=True)
stocks = provider.get_all_a_stocks()
data = provider.get_data_matrices(stocks[:300], "2024-09-01", "2024-12-31")

# 计算因子
calculator = FactorCalculator()
factors = calculator.calculate_factors(data)

# 生成信号
params = SignalParams()
engine = SignalEngine(params=params)
signals = engine.generate_signals(data, factors, params)

# 运行回测
backtest = VBTBacktest()
result = backtest.run(data, factors, params)

print(f"年化收益: {result.annual_return:.2f}%")
print(f"夏普比率: {result.sharpe_ratio:.2f}")
```
