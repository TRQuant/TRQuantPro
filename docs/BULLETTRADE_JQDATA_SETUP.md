# BulletTrade JQData配置指南

## 快速开始

### 1. 创建.env文件

复制 `.env.example` 为 `.env` 并填入JQData账号密码：

```bash
cp .env.example .env
# 编辑.env文件，填入真实的JQData账号密码
```

### 2. 运行验证脚本

```bash
python scripts/test_bullettrade_working_final.py
```

## Windows端同步

1. `git pull origin ope`
2. 复制 `.env.example` 为 `.env`
3. 编辑 `.env` 填入JQData账号密码
4. 运行验证脚本
