## 五、MCP工具清单

### 数据源相关工具

```python
# JQData
datasource.fetch_all        # 获取所有数据
datasource.fetch_price      # 获取行情
datasource.fetch_financial  # 获取财务

# RawDoc
doc.store                   # 存储文档
doc.query                   # 查询文档
doc.list                    # 列出文档

# 事件抽取
event.extract               # 抽取事件
event.stage_mapping         # 阶段映射

# AltData Tier2
altdata.bid_store           # 存储招投标
altdata.bid_query           # 查询招投标
altdata.job_store           # 存储招聘
altdata.job_query           # 查询招聘
altdata.generate_signals    # 生成信号
```

## 六、后续开发计划

### Phase 5: 爬虫模块开发

| 优先级 | 模块 | 数据源 | 预计工作量 |
|--------|------|--------|-----------|
| P0 | 公告爬虫 | 巨潮资讯网 | 2天 |
| P1 | 互动易爬虫 | 上证e互动 | 1天 |
| P2 | 招投标爬虫 | 官方平台 | 2天 |
| P3 | 招聘爬虫 | BOSS/拉勾 | 1天 |

### 开发原则

1. **不做全量爬取** - 只爬取特定公司/关键词
2. **合规优先** - 仅爬取公开信息
3. **落入RawDoc** - 统一存储格式
4. **事件抽取** - 规则+LLM辅助
