## 📚 研究系统（Jupyter Notebook）

### 架构定位

TRQuant采用**研究-实战双阶段分离架构**：

```
研究阶段 (Research Phase)
└── Jupyter Notebook
    ├── 数据探索和分析
    ├── 模型开发和验证
    ├── 专业数据可视化
    └── 研究报告生成

实战阶段 (Production Phase)
└── GUI面板 + API
    ├── 策略执行
    ├── 实盘交易
    ├── 监控和管理
    └── 结果展示
```

### Notebook功能

1. **市场分析研究**
   - 市场环境识别可视化
   - 多指数技术图表（上证、深证、创业板、科创板）
   - 市场状态仪表盘
   - 多周期预测分析

2. **数据可视化**
   - 使用 ChartEngine 生成专业图表
   - 使用 MarketGauge 创建仪表盘
   - Bloomberg风格的金融图表
   - 交互式图表（Plotly）

3. **研究工具集成**
   - 与核心模块无缝集成
   - 数据获取（JQData优先）
   - 模型验证和回测
   - 结果导出和报告生成

### 主要Notebook

- `notebooks/research/03_market_env_concise_v3.ipynb` - 市场环境识别可视化
- `notebooks/research/01_market_trend_comprehensive.ipynb` - 市场趋势综合分析
- `notebooks/research/02_market_trend_backtest_validation.ipynb` - 回测验证

### 技术特点

- ✅ **专业图表风格**: 参考Bloomberg等专业金融机构
- ✅ **多数据源支持**: JQData（优先）+ AKShare（补充）
- ✅ **交互式分析**: Plotly交互图表
- ✅ **模块化设计**: 可复用的可视化组件
