## 🔍 策略运行流程

### 初始化阶段

1. **加载股票池**: 从沪深300获取成分股（约300只）
2. **设置股票池**: 调用`set_universe()`设置股票池
3. **设置定时任务**: 每日14:50风控检查

### 每日运行流程

1. **盘前（周一）**: 更新股票池，过滤退市股票
2. **盘中（09:35，周一）**: 执行调仓
3. **盘中（14:50）**: 执行风控检查（止损/止盈）
4. **盘后**: 输出每日统计

### 选股流程

1. **计算因子**: 计算7个已验证因子
2. **计算总分**: 加权求和得到总分
3. **应用筛选**: 应用阈值筛选
4. **排序选股**: 按总分排序，选择前10只

### 风控流程

1. **检查持仓**: 遍历所有持仓
2. **计算盈亏**: 计算每只股票的盈亏比例
3. **执行止损**: 如果亏损>=8%，卖出
4. **执行止盈**: 如果盈利>=30%，卖出
5. **移动止损**: 如果盈利>=15%后回撤>=8%，卖出
6. **分批止盈**: 如果盈利>=20%，卖出50%
7. **时间止损**: 如果持仓>=20天，卖出

## 📈 回测报告解读

### 关键指标

1. **总收益率**: 策略总收益 / 初始资金
2. **年化收益率**: (总收益率 + 1)^(365/回测天数) - 1
3. **最大回撤**: 最大净值回撤幅度
4. **夏普比率**: (年化收益率 - 无风险利率) / 年化波动率
5. **胜率**: 盈利交易数 / 总交易数
6. **平均盈亏比**: 平均盈利 / 平均亏损

### 费用分析

- **总费用**: 佣金 + 印花税 + 过户费 + 监管费
- **费用占比**: 总费用 / 总交易额
- **单笔平均费用**: 总费用 / 总交易数

## ⚠️ 注意事项

### 1. 数据质量

- 确保QMT数据源正常
- 检查股票池是否包含退市股票（策略会自动过滤）
- 验证因子计算是否正确

### 2. 佣金设置

- 策略代码中已设置佣金参数
- QMT回测界面中的佣金设置会被策略代码覆盖
- 如需修改佣金，请修改策略代码中的参数

### 3. 回测时间

- 策略自动计算最近3个月
- 如需修改回测时间，请修改策略代码中的`START_DATE`和`END_DATE`

### 4. 性能优化

- 验证股票可交易性会消耗时间（每周一次）
- 初始化时跳过验证以加快启动速度
- 每周更新股票池时进行验证
