## 🔧 修复的问题

### 问题1: 组合关键词搜索返回0结果

**问题**: "聚宽 因子"查询返回0个结果

**原因**: 知识库搜索是简单的字符串匹配，不支持AND逻辑

**修复**: 
- 将"聚宽 因子"改为"因子构建"
- "因子构建"是实际存在的标签和关键词
- 能够找到相关结果

### 问题2: source字段可能为None导致错误

**问题**: `TypeError: 'NoneType' object is not subscriptable`

**原因**: `item.get('source')`可能返回None

**修复**:
```python
# 修复前
source = item.get('source', 'N/A')
print(f"     URL: {source[:80]}")  # source可能为None

# 修复后
source = item.get('source') or item.get('url') or ''
if source:
    print(f"     URL: {str(source)[:80]}")
```

## 📋 知识库搜索能力说明

### 支持的搜索方式

1. **单关键词搜索** ✅
   - 例如：`"JQData"`, `"Alpha"`, `"因子"`

2. **短语搜索** ✅
   - 例如：`"Alpha101"`, `"CNE5"`, `"因子构建"`

3. **部分匹配** ✅
   - 例如：`"API"` 会匹配包含"API"的所有内容

### 不支持的搜索方式

1. **AND逻辑** ❌
   - 例如：`"聚宽 因子"` 不会同时匹配包含"聚宽"和"因子"的内容
   - 只会查找包含完整字符串"聚宽 因子"的内容

2. **OR逻辑** ❌
   - 例如：`"Alpha|因子"` 不会匹配包含"Alpha"或"因子"的内容

3. **NOT逻辑** ❌
   - 例如：`"-测试"` 不会排除包含"测试"的内容
