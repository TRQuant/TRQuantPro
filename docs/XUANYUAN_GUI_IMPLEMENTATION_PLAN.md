## 🔧 技术实现要点

### 1. 输入对话框
使用`QDialog` + `QFormLayout`创建表单：
```python
dialog = QDialog(self)
form = QFormLayout(dialog)
name_input = QLineEdit()
content_input = QPlainTextEdit()  # 多行文本
form.addRow("名称:", name_input)
form.addRow("内容:", content_input)
```

### 2. 列表显示
使用`QTableWidget`显示结构化数据：
```python
table = QTableWidget()
table.setColumnCount(4)
table.setHorizontalHeaderLabels(["名称", "分类", "标签", "创建时间"])
table.setRowCount(len(templates))
```

### 3. 结果格式化
将JSON结果转换为易读格式：
```python
def format_template_result(data):
    if data.get("success"):
        template = data.get("template", {})
        return f"""
名称: {template.get('name')}
分类: {template.get('category')}
内容:
{template.get('content')}
        """
```

### 4. 异步调用
使用已有的`XuanyuanWorker`机制，添加进度提示。
