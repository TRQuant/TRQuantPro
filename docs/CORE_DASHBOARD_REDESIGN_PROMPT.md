# 核心仪表盘重新设计 Prompt

## 目标
重新设计一个功能完整、视图美观的核心仪表盘，展示多指数的趋势强度、风险水平、建议仓位三大核心指标。

## 功能需求

### 1. 数据展示
- **支持多指数**：最多显示4个指数（上证、深证、创业板、科创50）
- **三大核心指标**：
  - 趋势强度（-100 到 +100，仪表盘显示）
  - 风险水平（低/中/高，仪表盘显示）
  - 建议仓位（百分比，仪表盘显示）
- **环境状态**：显示每个指数的市场环境（牛市/熊市/震荡/转折）

### 2. 视觉设计

#### 布局要求
- **响应式布局**：根据指数数量自动调整（1-4个指数）
- **清晰的分组**：每个指数一行，每行3个仪表盘
- **合理的间距**：元素之间不堆积，有足够的呼吸空间
- **对齐规范**：所有元素严格对齐，视觉整齐

#### 颜色方案
- **背景**：深色主题（`#1a1a2e`）
- **文字**：白色（`#ffffff`）
- **趋势强度**：
  - 正值（绿色系）：`#4CAF50`（强）到 `#8BC34A`（弱）
  - 负值（红色系）：`#F44336`（强）到 `#EF5350`（弱）
  - 接近0（黄色系）：`#FFC107`
- **风险水平**：
  - 低风险：`#4CAF50`
  - 中风险：`#FF9800`
  - 高风险：`#F44336`
- **建议仓位**：
  - 高仓位（>70%）：`#4CAF50`
  - 中仓位（30-70%）：`#FF9800`
  - 低仓位（<30%）：`#F44336`

#### 字体和大小
- **主标题**：16px，加粗，居中
- **列标题**：13px，加粗，居中
- **指数名称**：13px，加粗
- **环境状态**：12px，常规

### 3. 交互体验
- **悬停提示**：鼠标悬停显示详细数值
- **清晰的数据标签**：每个仪表盘显示当前数值
- **状态指示**：用颜色和文字清晰表示当前状态

## 技术实现要求

### 1. 使用 Plotly
- 使用 `plotly.graph_objects` 和 `plotly.subplots.make_subplots`
- 使用 `go.Indicator` 创建仪表盘
- 使用 `fig.add_annotation` 添加文本标签

### 2. 布局计算
- **动态计算子图位置**：根据指数数量动态创建布局
- **精确的 annotation 定位**：使用 paper 坐标系，确保对齐
- **自适应高度**：根据指数数量调整图表高度

### 3. 代码质量
- **清晰的注释**：每个关键步骤都有注释
- **模块化设计**：易于维护和扩展
- **错误处理**：处理数据缺失等异常情况

## 关键参数

### 间距参数
- `vertical_spacing`: 0.15-0.20（子图垂直间距）
- `horizontal_spacing`: 0.10-0.15（子图水平间距）
- `margin`: `dict(l=150, r=50, t=100, b=50)`（边距）

### 尺寸参数
- `height`: `150 * num_indices`（图表高度）
- 仪表盘尺寸：适中，不拥挤也不空旷

### 位置参数
- 列标题：`y=0.95`（paper 坐标系）
- 指数名称：动态计算，与每行中心对齐
- 主标题：居中，`x=0.5`

## 验收标准

1. ✅ **功能完整**：所有指数和指标都正确显示
2. ✅ **视觉美观**：颜色协调，布局清晰，不堆积
3. ✅ **对齐准确**：所有元素严格对齐
4. ✅ **响应式**：支持1-4个指数的动态布局
5. ✅ **交互友好**：有悬停提示，数据清晰可读

## 实现步骤

1. 创建动态布局（根据指数数量）
2. 添加列标题（独立的 annotation）
3. 为每个指数创建3个仪表盘
4. 添加指数名称和环境状态（左侧 annotation）
5. 设置全局样式和布局
6. 优化间距和对齐

## 注意事项

- 避免使用 `subplot_titles` 创建列标题（位置难以控制）
- 使用独立的 `annotation` 精确控制所有文本位置
- 确保所有计算都基于 paper 坐标系（0-1范围）
- 测试不同数量的指数（1个、2个、3个、4个）确保布局正确
