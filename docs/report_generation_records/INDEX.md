# 报告生成记录索引

> 所有十倍股报告的生成记录存档

## 📁 记录文件说明

每次生成报告时，会自动创建一个JSON记录文件，包含：
- 报告文件路径
- 生成时间
- 使用账号
- 数据范围
- 统计摘要

## 📋 生成记录列表

| 时间 | 账号 | 报告类型 | 评估数 | 推荐数 | 记录文件 |
|------|------|----------|--------|--------|----------|
| 2025-12-26 04:12 | 13327806797 | 完整8标签页 | 100 | 0 | tenbagger_complete_20251226_041228.json |
| 2025-12-26 04:11 | 13327806797 | 完整8标签页 | - | - | tenbagger_full_20251226_041145.json |

## 🔧 生成方法

### 1. 快捷运行
```bash
python scripts/run_tenbagger_report.py
```

### 2. 直接运行主脚本
```bash
python scripts/tenbagger_reports/generate_tenbagger_full_report.py
```

### 3. 脚本参数修改
编辑 `scripts/tenbagger_reports/generate_tenbagger_full_report.py`：
```python
# 账号配置
username = "13327806797"
password = "Taorui888"
```

## 📊 输出位置

- **HTML报告**: `reports/tenbagger_full_report_{账号}_{时间戳}.html`
- **生成记录**: `docs/report_generation_records/tenbagger_full_{时间戳}.json`
