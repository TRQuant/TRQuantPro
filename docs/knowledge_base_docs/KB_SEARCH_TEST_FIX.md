## 🔍 问题分析

### 原始问题

测试成功率96.4%（27/28），有一个测试失败：
- **"聚宽 因子"** 查询返回0个结果

### 原因分析

1. **组合关键词搜索限制**
   - 知识库搜索是简单的字符串匹配（`query_lower in text`）
   - 不支持AND逻辑（同时包含多个关键词）
   - "聚宽 因子" 作为整体字符串在内容中可能不存在

2. **测试用例设计问题**
   - 组合关键词测试不符合实际搜索能力
   - 应该使用单个关键词或实际存在的短语

## ✅ 修复方案

### 1. 修改测试用例

**修改前**:
```python
("聚宽 因子", "组合关键词 - 聚宽因子"),
```

**修改后**:
```python
("因子构建", "因子构建关键词搜索"),
```

**原因**:
- "因子构建"是实际存在的标签和关键词
- 符合知识库搜索的实际能力
- 能够找到相关结果

### 2. 增强错误处理

**修改前**:
```python
source = item.get('source', 'N/A')
print(f"     URL: {source[:80]}")  # 可能source为None导致错误
```

**修改后**:
```python
source = item.get('source') or item.get('url') or ''
if source:
    print(f"     URL: {str(source)[:80]}")
```

**原因**:
- 处理source可能为None的情况
- 支持多种字段名（source、url）
- 避免TypeError

### 3. 改进详情获取显示

**修改后**:
```python
source = item.get('source') or item.get('url') or ''
if source:
    print(f"   URL: {str(source)[:80]}")
tags = item.get('tags', [])
if tags:
    print(f"   标签: {', '.join(tags[:10])}")
```

**原因**:
- 更安全的字段访问
- 只在有值时才显示
- 避免空值显示

## 📝 知识库搜索能力说明

### 支持的搜索方式

1. **单关键词搜索** ✅
   - 例如：`"JQData"`, `"Alpha"`, `"因子"`

2. **短语搜索** ✅
   - 例如：`"Alpha101"`, `"CNE5"`, `"因子构建"`

3. **部分匹配** ✅
   - 例如：`"API"` 会匹配包含"API"的所有内容

### 不支持的搜索方式

1. **AND逻辑** ❌
   - 例如：`"聚宽 因子"` 不会同时匹配包含"聚宽"和"因子"的内容
   - 只会查找包含完整字符串"聚宽 因子"的内容

2. **OR逻辑** ❌
   - 例如：`"Alpha|因子"` 不会匹配包含"Alpha"或"因子"的内容

3. **NOT逻辑** ❌
   - 例如：`"-测试"` 不会排除包含"测试"的内容

### 搜索策略建议

如果需要进行组合搜索，可以：
1. 使用单个更具体的关键词（如"因子构建"而不是"聚宽 因子"）
2. 多次搜索然后合并结果
3. 使用标签过滤（`type`参数）
