## 🏗️ V2知识库结构重构

### 新增4个顶层知识域（与现有分类并行）

#### 1. 市场状态识别（Market Regime）

**路径**: `knowledge_base/market_regime/`

**目标**: 回答"什么时候用什么策略？"

**知识条目结构**:
```json
{
  "id": "mr_001",
  "title": "情绪退潮判定标准",
  "type": "market_regime",
  "regime_type": "退潮期",
  "indicators": ["涨停家数", "炸板率", "连板高度"],
  "thresholds": {
    "涨停家数": "< 10",
    "炸板率": "> 30%",
    "连板高度": "< 3板"
  },
  "strategy_implications": [
    "降低仓位",
    "避免追涨",
    "关注防御性标的"
  ],
  "examples": ["2023-03-15", "2024-08-20"],
  "source": "实战经验"
}
```

**需要补充的知识**:
- [ ] 情绪周期判定（冷启动/主升/过热/退潮/崩溃）
- [ ] 趋势/震荡/崩溃识别
- [ ] 流动性宽松/收缩判断
- [ ] 涨停家数 + 炸板率 → 情绪退潮
- [ ] 资金净流入为正但指数不涨 → 含义
- [ ] 高换手 + 缩量回调 → 强势/诱多判断

## 🔧 新增工具和框架

### 1. 因子评估引擎（Factor Evaluation Engine）

**功能**: 自动化IC/IR/衰减分析，结果写回知识库

**实现路径**: `core/factor_evaluation/`

**功能模块**:
- IC计算（因子与收益相关性）
- IC衰减分析（因子有效期）
- 分情绪区间IC（不同市场状态下的有效性）
- 因子组合协同性分析
- 结果自动写回知识库

**输出示例**:
```json
{
  "factor": "money_flow_main",
  "ic_mean": 0.12,
  "ic_std": 0.08,
  "ir": 1.5,
  "ic_by_regime": {
    "主升期": 0.18,
    "退潮期": -0.03,
    "震荡期": 0.05
  },
  "decay_period": 5,
  "recommendation": "主升期有效，退潮期失效"
}
```

### 2. 市场情绪状态机（Market Regime State Machine）

**功能**: 每天自动判断市场状态，限制策略生成空间

**实现路径**: `core/market_regime/state_machine.py`

**状态定义**:
- 冷启动（Cold Start）
- 主升（Rising）
- 过热（Overheated）
- 退潮（Retreat）
- 崩溃（Crash）

**判断逻辑**:
```python
def judge_market_regime(indicators):
    """
    基于多个指标判断市场状态
    """
    # 涨停家数、炸板率、连板高度
    # 资金流向、成交量、波动率
    # 综合判断 → 返回状态
    pass
```

**策略生成限制**:
- 退潮期：禁止生成追涨策略
- 过热期：降低仓位上限
- 崩溃期：只允许防御性策略

### 3. 策略生成Prompt模板（Strategy Generation Templates）

**功能**: 固定几类Prompt，而非自由对话

**实现路径**: `core/strategy_generation/prompts/`

**模板类型**:
- 短线策略生成模板
- 趋势策略生成模板
- 风控/减仓模板
- 情绪周期策略模板

**模板结构**:
```python
SHORT_TERM_STRATEGY_TEMPLATE = """
基于以下市场状态和可用因子，生成短线策略：

市场状态: {market_regime}
可用因子: {available_factors}
资金结构: {capital_structure}

要求：
1. 明确入场信号（基于因子组合）
2. 明确出场信号
3. 风险控制措施
4. 适用区间说明
5. 失败案例参考

输出格式：
- 策略逻辑
- 风险声明
- 适用区间
"""
```
