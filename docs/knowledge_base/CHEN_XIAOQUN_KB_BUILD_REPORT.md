## 📚 知识库内容详情

### 1. 核心战法体系

#### 1.1 三板斧战法
- **首板卡位术（10%试错仓）**: 早盘9:35前涨停，流通市值<30亿，封单量>2%
- **二板定龙术（50%主攻仓）**: 换手率>25%，板块内3只以上跟风涨停
- **三板加速术（40%加仓仓）**: 缩量涨停或量能持续放大，板块效应增强

#### 1.2 龙头战法
- **聚焦总龙头**: 只参与市场辨识度最高的龙头股
- **重仓持有**: 在龙头启动期重仓介入
- **坚定持有**: 不爱做T，看准就坚定持有到巅峰

#### 1.3 合力情绪战法
- **市场合力高于一切**: 识别并跟随市场合力
- **精准择时**: 在题材发酵初期介入
- **严格纪律**: 在行情震荡或出现风险信号时，果断止盈离场

### 2. 情绪周期把控

四个阶段策略：
- **启动期**: 轻仓试错（10%）
- **加速期**: 重仓持有（50%+）
- **高位震荡期**: 逐步减仓
- **退潮期**: 空仓观望

### 3. 实战心法

- **选股"三高"筛龙**: 高辨识度、高资金、高联动
- **交易频率控制**: 每月只做1-2笔交易
- **收益目标管理**: 年化收益目标30%
- **市场规则**: 对市场规则了然于胸，顺势而为

### 4. 实战案例

#### 案例1: 航天发展
- **操作**: 在商业航天板块中，率先斥资1.84亿埋伏入场
- **结果**: 带动多路游资跟风，推动个股走出5连板
- **退出**: 在行情震荡时，及时清仓离场，保住收益
- **战法**: 合力情绪战法

#### 案例2: 中交地产
- **操作**: 重仓持有
- **结果**: 21天内实现11个涨停板
- **退出**: 持有至见顶或出现停牌风险
- **战法**: 龙头战法
