# 知识库可靠性标准

> **版本**: v1.0  
> **更新**: 2026-01-13  
> **目的**: 定义知识库知识的可靠性评级标准，确保知识质量

---

## 📊 可靠性评级标准

### A级（高可靠性）

**标准**:
- ✅ 回测验证 + 实战验证
- ✅ 有量化数据支撑（IC、IR、胜率等）
- ✅ 样本量足够大（>1000次）
- ✅ 数据来源可追溯

**示例**:
- 回测数据验证（2020-2024，15,678次信号）
- IC值、IR值、胜率等量化指标
- 数据来源：TRQuant回测引擎、JQData

**使用建议**:
- 可以直接用于策略生成
- 可以作为决策依据
- 优先级最高

---

### B级（中高可靠性）

**标准**:
- ✅ 回测验证或实战验证
- ✅ 有部分数据支撑
- ✅ 样本量中等（>100次）
- ✅ 数据来源可追溯

**示例**:
- 实战验证（2023-2024，156次交易）
- 专业文献（经过同行评议）
- 数据来源：实战账户、专业研究

**使用建议**:
- 可以用于策略生成，但需要谨慎
- 可以作为参考依据
- 优先级较高

---

### C级（中等可靠性）

**标准**:
- ⚠️ 实战经验总结
- ⚠️ 无量化数据支撑
- ⚠️ 样本量较小（<100次）
- ⚠️ 数据来源不明确

**示例**:
- 实战经验总结
- 个人观察和总结
- 数据来源：个人经验

**使用建议**:
- 可以作为参考，但需要验证
- 不应直接用于策略生成
- 优先级中等

---

### D级（低可靠性）

**标准**:
- ❌ 理论推导
- ❌ 未经验证的经验
- ❌ 无数据支撑
- ❌ 数据来源不明确

**示例**:
- 理论推导
- 未经验证的假设
- 数据来源：理论分析

**使用建议**:
- 仅作为参考，需要大量验证
- 不应直接用于策略生成
- 优先级最低

---

## 📋 知识来源分类

### 1. 回测数据验证

**特点**:
- 基于历史数据
- 有量化指标（IC、IR、胜率等）
- 样本量通常较大

**可靠性**: A级或B级

**示例**:
- "MACD金叉在主升期的有效性（回测验证）"
- 数据周期：2020-2024
- 样本数量：15,678次信号

---

### 2. 实战验证

**特点**:
- 基于真实交易
- 有交易记录
- 样本量通常较小

**可靠性**: B级或C级

**示例**:
- "板块轮动策略在主升期的实战表现（实战验证）"
- 验证周期：2023-2024
- 实战次数：156次交易

---

### 3. 专业文献

**特点**:
- 经过同行评议
- 有研究方法说明
- 数据来源可追溯

**可靠性**: B级

**示例**:
- "情绪周期理论（专业文献）"
- 文献来源：《A股情绪周期研究》（2023）
- 研究方法：时间序列分析

---

### 4. 实战经验总结

**特点**:
- 基于个人经验
- 无量化数据支撑
- 样本量不明确

**可靠性**: C级

**示例**:
- "高换手率在不同阶段的含义（实战经验总结）"
- 来源：个人实战经验
- 无量化数据支撑

## 🎯 知识补充原则

### 1. 优先补充高可靠性知识

- **A级知识**: 优先补充，直接用于策略生成
- **B级知识**: 次优先补充，谨慎使用
- **C级知识**: 作为补充，需要验证
- **D级知识**: 尽量避免，仅作为参考

### 2. 明确标注来源和可靠性

每条知识必须包含：
- **来源类型**: 回测验证/实战验证/专业文献/实战经验
- **可靠性评级**: A/B/C/D级
- **数据来源**: 具体的数据来源和验证方法
- **样本量**: 样本数量或验证次数

### 3. 定期更新和验证

- **定期回测**: 定期回测验证知识的有效性
- **更新数据**: 更新回测数据和实战数据
- **验证结果**: 记录验证结果，更新可靠性评级

## 🔍 知识验证方法

### 1. 回测验证

**步骤**:
1. 定义验证指标（IC、IR、胜率等）
2. 选择回测周期和样本
3. 运行回测，收集数据
4. 分析结果，计算可靠性指标
5. 更新知识条目，标注可靠性

**示例**:
```python
# 回测验证MACD金叉信号
backtest_result = {
    "period": "2020-2024",
    "sample_size": 15678,
    "win_rate": 0.685,
    "ic": 0.18,
    "ir": 1.2,
    "reliability": "A级"
}
```

### 2. 实战验证

**步骤**:
1. 定义验证指标（胜率、平均收益、最大回撤等）
2. 在实盘账户中验证
3. 记录交易数据
4. 分析结果，计算可靠性指标
5. 更新知识条目，标注可靠性

**示例**:
```python
# 实战验证板块轮动策略
practice_result = {
    "period": "2023-2024",
    "sample_size": 156,
    "win_rate": 0.641,
    "avg_return": 0.118,
    "max_drawdown": -0.092,
    "reliability": "B级"
}
```

### 3. 专业文献验证

**步骤**:
1. 查找相关专业文献
2. 验证文献的可靠性（同行评议、数据来源等）
3. 提取关键结论
4. 标注来源和可靠性

**示例**:
```python
# 专业文献验证
literature_result = {
    "source": "《A股情绪周期研究》（2023）",
    "method": "时间序列分析",
    "sample_size": "2018-2023",
    "accuracy": 0.785,
    "reliability": "B级"
}
```
