# 聚宽API爬虫 - 优化项清单

> 创建时间: 2026-01-01
> 优化版本: `scripts/crawl_jqdata_optimized.py`

---

## ✅ 已实现的优化项

### 1. 重试机制 ✅

**实现**:
- 失败自动重试（默认3次）
- 指数退避策略（重试延迟递增）
- 失败URL记录到文件

**配置**:
```python
"retry_times": 3,      # 重试次数
"retry_delay": 5,      # 重试延迟（秒）
```

**优势**:
- 提高成功率（网络波动时自动重试）
- 减少人工干预

---

### 2. 进度保存与恢复 ✅

**实现**:
- 定期保存进度（每10个页面）
- 支持中断后恢复
- 保存visited_urls、failed_urls、统计信息

**文件**:
- `crawl_progress.json` - 完整进度
- `visited_urls.json` - 已访问URL
- `failed_urls.json` - 失败URL

**优势**:
- 中断后无需重新开始
- 节省时间和资源

---

### 3. 速率限制 ✅

**实现**:
- 请求间隔（默认2秒）
- 避免请求过快被封

**配置**:
```python
"rate_limit_delay": 2,  # 请求间隔（秒）
```

**优势**:
- 降低被封风险
- 更稳定的爬取

---

### 4. 错误处理增强 ✅

**实现**:
- 三层降级等待策略（networkidle -> load -> domcontentloaded）
- 异常捕获和记录
- 失败URL单独记录

**优势**:
- 更好的容错性
- 详细的错误信息

---

### 5. 详细日志记录 ✅

**实现**:
- 实时显示爬取进度
- 统计信息详细记录
- 错误信息完整记录

**统计项**:
- 总链接数
- 已爬取/成功/失败/跳过
- 重试次数
- 存入知识库数量
- 耗时统计

---

### 6. 内存优化 ✅

**实现**:
- 使用deque队列（更高效）
- 分批处理（每批50个页面）
- 及时释放不需要的数据

**配置**:
```python
"batch_size": 50,  # 每批处理的页面数
```

---

### 7. 中断处理 ✅

**实现**:
- KeyboardInterrupt捕获
- 中断时保存进度
- 优雅关闭浏览器

**优势**:
- Ctrl+C安全中断
- 不丢失已爬取数据

---

## 📊 性能优化

### 等待时间优化

**当前配置**（已验证有效）:
```python
"wait_timeout": 60000,          # 60秒超时
"networkidle_wait": 3000,       # 3秒networkidle等待
"extra_wait": 5000,             # 5秒额外等待（普通页面）
"main_page_extra_wait": 8000,   # 8秒额外等待（主页面）
```

**说明**:
- 主页面需要更长时间（确保侧栏菜单渲染）
- 普通页面5秒足够
- 60秒超时足够，无超时情况

---

### 并发控制

**当前配置**:
```python
"concurrent_pages": 1,  # 串行（避免被封）
```

**说明**:
- 目前使用串行（安全）
- 可以后续优化为并行（需要更复杂的控制）

## 🔧 配置说明

### 完整配置

```python
CONFIG = {
    "max_depth": 3,                    # 最大递归深度
    "max_pages": 1000,                 # 最大页面数
    "wait_timeout": 60000,             # 超时（毫秒）
    "networkidle_wait": 3000,          # networkidle等待（毫秒）
    "extra_wait": 5000,                # 额外等待（毫秒）
    "main_page_extra_wait": 8000,      # 主页面额外等待（毫秒）
    "retry_times": 3,                  # 重试次数
    "retry_delay": 5,                  # 重试延迟（秒）
    "rate_limit_delay": 2,             # 请求间隔（秒）
    "batch_size": 50,                  # 每批处理的页面数
    "progress_save_interval": 10,      # 进度保存间隔（页）
    "concurrent_pages": 1,             # 并发页面数
}
```

- 需要：共享进度状态（Redis等）
