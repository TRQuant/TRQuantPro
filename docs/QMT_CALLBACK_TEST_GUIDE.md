# QMT回调函数测试指南

## 问题

策略的`init()`函数被调用，但`handlebar()`、`before_trading_start()`和`after_trading_end()`回调函数未被调用。

## 测试步骤

### 步骤1：使用简单测试策略

1. 在QMT中加载测试策略：`strategies/qmt/QMT_TEST_SIMPLE.py`
2. 设置回测参数：
   - 起始日期：2025-10-11
   - 结束日期：2026-01-09
   - 初始资金：1000000（100万）
3. 点击"运行"或"开始回测"

### 步骤2：检查日志输出

**如果看到**：
```
[TEST] init() function called
[TEST] before_trading_start() function called
[TEST] handlebar() function called
[TEST] after_trading_end() function called
```

说明回调函数正常工作，问题可能在主策略代码中。

**如果只看到**：
```
[TEST] init() function called
```

说明QMT没有调用其他回调函数，可能是：
1. 回测没有实际运行（只是加载了策略）
2. QMT回测设置问题
3. QMT版本或配置问题

### 步骤3：检查QMT回测设置

#### 3.1 确认回测已启动

- ✅ 策略文件已加载
- ❓ 回测是否已实际启动（不只是加载策略）
- ❓ 是否点击了"运行"或"开始回测"按钮
- ❓ 是否有回测进度条或状态显示

#### 3.2 检查回测参数

- **起始日期**：2025-10-11（必须是交易日）
- **结束日期**：2026-01-09（必须是交易日）
- **初始资金**：>= 1000000（建议至少100万）
- **回测模式**：研究环境（不是实盘环境）

#### 3.3 检查交易日

确认日期范围内有交易日：
- 2025-10-11 是周六（非交易日）
- 2025-10-13 是周一（交易日）
- 建议使用：2025-10-13 到 2026-01-09

### 步骤4：尝试不同的日期范围

如果简单测试策略也没有输出回调函数日志，尝试：

1. **更短的日期范围**：
   - 起始日期：2025-12-01
   - 结束日期：2025-12-31
   - 初始资金：1000000

2. **确认包含交易日**：
   - 避免周末和节假日
   - 使用周一到周五的日期

### 步骤5：检查QMT版本和文档

1. 查看QMT版本号
2. 查看QMT官方文档：
   - 研究环境回测的正确使用方法
   - `handlebar()`回调函数的调用时机
   - 是否有特定的配置要求

### 步骤6：联系QMT技术支持

如果以上步骤都不行，可能需要联系QMT技术支持，询问：
1. 研究环境回测的正确使用方法
2. 为什么`handlebar()`回调函数未被调用
3. 是否有特定的配置或版本要求

## 预期结果

### 正常情况

每个交易日应该看到：
1. `[TEST] init() function called` - 只在初始化时一次
2. `[TEST] before_trading_start() function called` - 每个交易日开盘前
3. `[TEST] handlebar() function called` - 每个交易日盘中
4. `[TEST] after_trading_end() function called` - 每个交易日收盘后

### 异常情况

如果只看到`init()`日志，说明：
- 回测可能没有实际运行
- 或者QMT没有调用回调函数
