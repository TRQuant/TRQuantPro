# 聚宽股票专业版是否包含历史L2数据 - 说明文档

> **更新时间**: 2025-01-01  
> **数据来源**: 聚宽官方文档 + 网络验证  
> **账号类型**: 股票专业版（正式账号）

---

## ❌ 结论：股票专业版不包含历史L2数据

根据聚宽官方文档和公开信息，**股票专业版（正式账号）不包含历史L2数据（Level-2深度行情数据）**。

---

## 📊 详细说明

### 1. 聚宽提供的数据类型

聚宽股票专业版主要提供：

#### ✅ **L1数据（Level-1基础行情）**
- **包含内容**：
  - 最新价、开盘价、最高价、最低价
  - 成交量、成交额
  - 买卖一档价格和数量（买一/卖一）

- **数据接口**：
  - `get_price()` - 获取K线数据（日线、分钟线）
  - `get_current_data()` - 获取当前实时行情
  - `get_bars()` - 获取固定窗口K线数据

- **历史范围**：2005-01-01 至今（股票数据）

#### ⚠️ **Tick快照数据（仅限机构用户）**

根据聚宽官方文档（`docs/jqdata_crawled/032_JQData数据范围及接口更新时间.txt`）：

```
Tick快照数据（仅限机构用户）

股票Tick
get_ticks()
2010-01-01至今
盘后15:00更新，24:00入库
```

**重要说明**：
- ✅ **API接口存在**：`get_ticks()` 可以获取Tick数据
- ❌ **权限限制**：**仅限机构用户**（不是普通股票专业版用户）
- 📊 **数据内容**：包含五档买卖盘（a1_p~a5_p, b1_p~b5_p），但不是完整的L2数据

**Tick数据包含的字段**（以可转债Tick为例）：
- `time` - 时间
- `current` - 当前价
- `high/low` - 最高价/最低价
- `volume/money` - 累计成交量/成交额
- `a1_p~a5_p` - 五档卖价
- `a1_v~a5_v` - 五档卖量
- `b1_p~b5_p` - 五档买价
- `b1_v~b5_v` - 五档买量

**注意**：这是**五档行情**（L1.5），不是完整的L2数据（通常需要十档行情）。

#### ❌ **L2数据（Level-2深度行情）**

聚宽**不提供**完整的L2数据，包括：
- ❌ **十档行情**：买卖十档价格和数量
- ❌ **逐笔成交明细**：每笔成交的详细记录（时间、价格、数量、方向等）
- ❌ **逐笔委托明细**：委托单的详细记录
- ❌ **委托队列**：买卖盘委托队列信息
- ❌ **成交统计**：大单、中单、小单统计

---

### 2. L2数据 vs Tick快照数据对比

| 特性 | L1数据 | Tick快照数据（聚宽） | 完整L2数据 |
|------|--------|---------------------|-----------|
| **买卖盘档数** | 1档（买一/卖一） | 5档（买卖五档） | 10档（买卖十档） |
| **逐笔成交** | ❌ | ❌ | ✅ |
| **逐笔委托** | ❌ | ❌ | ✅ |
| **委托队列** | ❌ | ❌ | ✅ |
| **历史数据** | ✅ 2005年至今 | ⚠️ 仅限机构用户 | ❌ 聚宽不提供 |
| **权限要求** | 正式账号 | **机构用户** | 其他数据商 |

---

### 3. 股票专业版 vs 机构用户

| 项目 | 股票专业版（正式账号） | 机构用户 |
|------|---------------------|---------|
| **Tick数据（get_ticks）** | ❌ **不可用** | ✅ 可用（2010-01-01至今） |
| **L2数据** | ❌ 不提供 | ❌ 不提供 |
| **L1数据** | ✅ 可用（2005-01-01至今） | ✅ 可用 |

**结论**：
- **股票专业版**：只能获取L1数据（日线、分钟线、实时行情）
- **机构用户**：可以获取Tick快照数据（五档行情），但仍不是完整L2数据

---

### 4. 如何获取L2数据

如果您需要完整的L2数据（十档行情、逐笔成交、逐笔委托），需要：

#### 方案1：联系聚宽客服
- 咨询是否有L2数据服务（可能需要额外付费）
- 确认机构用户的详细权限和费用

#### 方案2：使用其他数据提供商
- **幕数据（mushuju.com）**：提供包含十档行情、逐笔成交、逐笔委托的L2数据服务
- **其他专业数据商**：如Wind、同花顺iFind等（通常费用较高）

#### 方案3：券商提供
- 部分券商可能通过其交易接口提供L2数据
- 需要咨询具体券商的数据服务

## 🔍 验证方法

### 方法1: 查看账号权限

```python
from jqdatasdk import auth, get_account_info

auth('your_username', 'your_password')
account_info = get_account_info()
print(account_info)
```

### 方法2: 尝试调用get_ticks()

```python
import jqdatasdk as jq

try:
    # 尝试获取Tick数据
    ticks = jq.get_ticks(
        '000001.XSHE',
        start_dt='2024-01-01 09:30:00',
        end_dt='2024-01-01 10:00:00',
        count=100
    )
    if ticks is not None and len(ticks) > 0:
        print("✅ 可以获取Tick数据")
        print(f"字段: {ticks.columns.tolist()}")
    else:
        print("❌ 无法获取Tick数据")
except Exception as e:
    error_msg = str(e)
    if "权限" in error_msg or "机构" in error_msg:
        print(f"❌ 权限不足: {error_msg}")
    else:
        print(f"错误: {e}")
```

**预期结果**（股票专业版）：
- 可能会报错提示需要机构用户权限
- 或者返回空数据
