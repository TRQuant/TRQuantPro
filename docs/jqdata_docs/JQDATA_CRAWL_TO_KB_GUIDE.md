# 聚宽数据页面完整爬取指南

> **创建时间**: 2025-01-01  
> **脚本**: `scripts/crawl_jqdata_all_subpages_to_kb.py`

---

## 🎯 功能说明

使用Playwright（最先进的爬虫工具）抓取聚宽数据页面的所有子网页，并自动存入知识库。

### 主要特性

1. **智能递归爬取**: 自动发现并爬取所有子页面
2. **JavaScript支持**: 使用Playwright处理JS渲染页面
3. **自动去重**: 避免重复爬取相同页面
4. **知识库集成**: 自动存入轩辕剑灵知识库
5. **文件备份**: 同时保存到本地文件
6. **进度显示**: 实时显示爬取进度和统计信息

---

## 📋 使用方法

### 基本用法

```bash
cd /home/taotao/dev/QuantTest/TRQuant
source venv/bin/activate
python scripts/crawl_jqdata_all_subpages_to_kb.py
```

### 配置选项

可以在脚本中修改以下参数：

- `JQDATA_DOC_URL`: 起始URL（默认：聚宽数据文档主页）
- `max_depth`: 最大爬取深度（默认：2层）
- `max_pages`: 最大爬取页面数（默认：500）

## ⚙️ 工作原理

### 1. 初始化

- 启动Playwright浏览器（headless模式）
- 访问起始URL

### 2. 页面爬取

对于每个页面：
1. 等待页面完全加载（networkidle）
2. 等待JS执行（2秒）
3. 提取HTML内容
4. 使用BeautifulSoup解析
5. 提取标题和主要内容
6. 提取所有子链接

### 3. 递归爬取

- 将发现的子链接加入队列
- 根据深度限制决定是否继续爬取
- 自动去重（避免重复爬取）

### 4. 存储

- 保存到本地文件（备份）
- 存入知识库（如果可用）

## 🛠️ 技术细节

### Playwright优势

1. **JavaScript支持**: 完美处理动态渲染页面
2. **自动等待**: 等待网络空闲，确保内容加载完成
3. **性能优秀**: 比Selenium快很多
4. **稳定可靠**: 官方维护，社区活跃

### 内容提取策略

1. 优先查找`<main>`标签
2. 其次查找`<body>`标签
3. 移除script、style、nav等无关内容
4. 清理多余空白字符

### 链接过滤规则

只保留以下类型的链接：
- 包含`/help/api/doc`的URL
- 包含`/help/api/help`的URL
- 包含`JQDatadoc`的URL
- 包含`JQData`的URL
- 域名必须是`joinquant.com`

---

## ⚠️ 注意事项

1. **请求频率**: 脚本在每次请求之间会等待1秒，避免请求过快
2. **深度限制**: 默认最大深度为2层，可以根据需要调整
3. **页面数量限制**: 默认最多爬取500个页面，防止无限递归
4. **内容长度**: 内容少于100字符的页面会被跳过

## 🔍 故障排查

### 问题1: Playwright未安装

**错误**: `Playwright未安装`

**解决**:
```bash
pip install playwright
playwright install chromium
```

### 问题2: 知识库工具不可用

**现象**: 脚本仍会运行，但不会存入知识库

**解决**: 检查`mcp_servers.unified_dev_server`是否正确导入

### 问题3: 页面加载超时

**现象**: 某些页面爬取失败

**解决**: 
- 检查网络连接
- 增加timeout时间（脚本中默认60秒）
