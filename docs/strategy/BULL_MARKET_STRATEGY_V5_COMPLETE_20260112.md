## 二、核心模块详解

### 2.1 市场特征分类器 (MarketCharacterClassifier)

**位置**: `core/strategy/market_character_classifier.py`

**功能**:
- 基于 `MarketTrendAnalyzerV3` (多周期共振 + HMM) 判断市场状态
- 自动识别: 快牛、慢牛、震荡、熊市
- 2019年春季慢牛特殊识别
- 输出自适应策略参数

**市场类型 → 策略模式映射**:

| 市场类型 | 策略模式 | 仓位上限 | 止损幅度 | 止盈幅度 |
|----------|----------|----------|----------|----------|
| 快牛     | 激进     | 100%     | -12%     | +50%     |
| 慢牛     | 保守     | 80%      | -8%      | +30%     |
| 震荡     | 正常     | 100%     | -10%     | +40%     |
| 熊市     | 防御     | 40%      | -6%      | +20%     |

### 2.2 题材识别器 (ThemeSectorIdentifier)

**位置**: `core/strategy/theme_sector_identifier.py`

**功能**:
- 从知识库加载当前热门题材 (AI主线、商业航天等)
- 解析 Tier1/Tier2 核心标的
- 生成题材因子，用于选股评分

**知识库来源**: `docs/AImainline011226/2.AI应用公司标的池构建深度研究.txt`

**当前识别的AI主线**:
1. AI智能体 (权重1.5) - 科大讯飞、昆仑万维、金山办公
2. AI办公 (权重1.3) - 金山办公、用友网络、万兴科技
3. AI营销 (权重1.2) - 蓝色光标、美图公司
4. AI工业软件 (权重1.1)
5. AI医疗健康 (权重1.0)

### 2.3 动态风控管理器 (DynamicRiskManager)

**位置**: `core/strategy/dynamic_risk_manager.py`

**功能**:
- 根据策略模式动态调整风控参数
- 涨停板特殊处理逻辑
- 卖出决策优先级排序

**交易规则 (保守模式示例)**:

```
【止损规则】
1. 硬止损: 亏损 8% 立即全部卖出
2. 软止损: 亏损 6% 且持仓满 3 天，卖出50%
3. 移动止损: 盈利超 12% 后，从最高点回撤 7% 全部卖出
4. 时间止损: 持仓满 15 天且亏损，全部卖出

【止盈规则】
1. 第一批止盈: 盈利 15%，卖出 40%
2. 全止盈: 盈利 30%，全部卖出

【涨停特殊处理】
1. 涨停不卖: 涨停当日不触发止盈
2. 首板观察期: 2 天 - 首板后不触发止损
3. 连板加仓: 连续涨停可考虑加仓
```

### 2.4 投资标的构建器 (InvestmentTargetBuilder)

**位置**: `core/strategy/investment_target_builder.py`

**功能**: 两阶段投资标的筛选

**Stage 1 - 初步筛选**:
- 排除ST、*ST股票
- 排除上市不足60天的次新股
- 排除科创板(688)、北交所(8/4开头)
- 流动性过滤 (最近5日平均成交量)
- 题材加分 (知识库驱动)

**Stage 2 - 信号评分选择**:
- 计算全因子矩阵
- 生成买入信号和评分
- 按综合得分排序，选择Top N

### 2.5 因子计算 (FactorCalculator)

**位置**: `core/research/factors.py`

**因子分类**:

| 类别 | 因子 | 来源 |
|------|------|------|
| 动量因子 | mom_20d, mom_5d, rel_position | 自定义计算 |
| 量价因子 | vol_ratio, vol_ratio_5d | 自定义计算 |
| **涨停因子** | is_limit_up, limit_up_count_5d, is_first_limit_up, limit_up_vol_ratio | 自定义计算 |
| 突破因子 | breakout_60d, breakout_ratio | 自定义计算 |
| 资金流向 | main_flow, flow_strength | 自定义计算 |
| JQData因子库 | size, momentum, liquidity, ROC6, ROC12, VOL20, PEG, roe_ttm 等 | JQData直调 |

**涨停因子详解**:
- `is_limit_up`: 当日涨幅 > 9.3% 视为涨停
- `limit_up_count_5d`: 近5日涨停次数
- `is_first_limit_up`: 首板信号 (前5日无涨停)
- `limit_up_vol_ratio`: 涨停当日量比

### 2.6 信号引擎 (SignalEngine)

**位置**: `core/research/signals.py`

**买入信号类型**:

| 信号 | 条件 | 基础得分 |
|------|------|----------|
| 首板启动 | is_first_limit_up AND limit_up_vol_ratio > 2.5 | 80-90 |
| 连板加速 | limit_up_count_5d >= 2 | 70-80 |
| 强势突破 | breakout_60d AND breakout_ratio > 5% AND mom_5d > 16% AND vol_ratio > 1.5 | 65-75 |
| 量价齐升 | mom_5d > 10% AND vol_ratio > 2.0 AND flow_strength > 0.5 | 60-70 |

**卖出信号**:
- 跌停信号
- RSI超卖
- 资金流出

## 四、回测结果分析

### 4.1 各时段表现

| 时段 | 市场类型 | 策略模式 | 总收益 | 年化 | 最大回撤 | 周均收益 |
|------|----------|----------|--------|------|----------|----------|
| 2024政策牛 | 震荡 | 保守 | -3.93% | -54.04% | 7.62% | -0.78% |
| 2024年末 | 震荡 | 保守 | +0.54% | +6.61% | 17.76% | +0.69% |
| 2020夏季牛 | 震荡 | 保守 | +6.45% | +61.16% | 29.75% | +1.42% |
| **2019春季慢牛** | 慢牛 | 保守 | **+13.80%** | **+103.06%** | 23.36% | **+1.51%** |

### 4.2 结果分析

**2019春季慢牛表现最佳**:
- V5成功识别为"慢牛"特殊时段
- 自动切换保守参数，避免追涨停
- 年化收益103%，周均1.51%

**2024政策牛表现不佳原因**:
- 市场被识别为"震荡"而非"快牛"
- 保守模式下仓位受限
- 需优化市场识别算法的阈值

### 4.3 改进方向

1. **优化市场识别阈值**: 调整快牛/震荡的判断边界
2. **增加激进模式触发**: 政策驱动的快牛应更早识别
3. **参数网格优化**: 针对不同市场类型进行参数调优

## 五、核心参数配置 (SignalParamsV4)

**位置**: `core/strategy/bull_market_params_v4.py`

```python
@dataclass
class SignalParamsV4:
    # === 涨停因子参数 (优化自chase-the-rise) ===
    limit_up_threshold: float = 0.093          # 涨停阈值 9.3%
    vol_ratio_threshold_first: float = 2.5     # 首板量比阈值
    
    # === 动量筛选参数 ===
    min_mom_20d: float = -1.25                 # 20日动量下限
    max_mom_20d: float = 25.0                  # 20日动量上限
    max_rel_position: float = 80.0             # 相对位置上限
    
    # === 信号阈值 ===
    min_signal_score: float = 52.0             # 最低信号得分
    min_vol_ratio: float = 1.0                 # 最低量比
    
    # === 仓位管理 ===
    max_positions: int = 5                     # 最大持仓数
    single_position_max: float = 0.4           # 单仓位上限 40%
    rebalance_period: int = 5                  # 调仓周期（周频）
    
    # === 止损止盈 ===
    stop_loss_pct: float = -0.06               # 硬止损 -6%
    soft_stop_loss_pct: float = -0.08          # 软止损 -8%
    soft_stop_loss_days: int = 3               # 软止损天数
    take_profit_pct: float = 0.4               # 全止盈 +40%
    partial_profit_1_pct: float = 0.2          # 第一批止盈 +20%
    partial_profit_1_ratio: float = 0.5        # 止盈比例 50%
    trailing_stop_trigger: float = 0.12        # 移动止损触发 +12%
    trailing_stop_pct: float = -0.06           # 移动止损回撤 -6%
    time_stop_days: int = 20                   # 时间止损天数
    
    # === 市场趋势参数 ===
    market_trend_score_bullish: float = 30.0   # 牛市阈值
    market_trend_score_bearish: float = -30.0  # 熊市阈值
```

- 连板股频繁出现

#### C类 - 商业航天/热门题材

- 量比 > 2.5 为佳
- 单只仓位不超过10%

### 6.3 交易策略执行

**入场规则**:
1. 首板启动信号优先（is_first_limit_up = True）
2. 量比 > 2.5
3. 信号得分 > 52

**仓位管理**:
- 单只不超过 20%
- 总仓位 60%-100%（根据市场状态）

**止损规则**:
- 硬止损: -10%（正常模式）/ -12%（激进模式）
- 涨停不卖
- 首板后2天不触发止损

**止盈规则**:
- +20% 卖出50%
- +40% 全部卖出

### 6.4 风险提示

1. ⚠️ 当前市场处于题材炒作期，波动较大
2. ⚠️ AI概念估值较高，需关注业绩验证
3. ⚠️ 商业航天连板后需谨慎追高，注意分歧日
4. ⚠️ 严格执行止损，保护本金
