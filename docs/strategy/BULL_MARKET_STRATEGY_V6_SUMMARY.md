## 📝 核心模块

### 1. MarketCharacterClassifierV6 (市场分类器)

**功能**: 分析市场状态，决定策略模式

**市场类型**:
- `EXTREME_BULL` (极端牛市): 快牛行情，超激进策略
- `BULL` (牛市): 正常牛市
- `SLOW_BULL` (慢牛): 震荡上行
- `RANGE` (震荡): 保守策略
- `BEAR` (熊市): 防御策略

**策略模式**:
- `ULTRA_AGGRESSIVE`: 满仓进攻，高换手
- `AGGRESSIVE`: 8成仓位，正常换手
- `NORMAL`: 6成仓位，稳健操作
- `CONSERVATIVE`: 4成仓位，控制风险
- `DEFENSIVE`: 清仓或极低仓位

**特殊处理**:
- 2019年春季慢牛自动识别
- 动量加分机制：连续上涨+高动量→提升信号强度

### 2. EventDrivenEngineV6 (事件驱动引擎)

**功能**: 生成交易信号

**信号类型**:
- 涨停首板启动
- 量价齐升
- 突破新高
- 主力资金流入

### 3. DynamicRiskManager (动态风险管理)

**功能**: 止损止盈控制

**风险参数**:
| 模式 | 止损 | 止盈 | 持仓上限 |
|------|------|------|----------|
| 超激进 | 8% | 30% | 100% |
| 激进 | 6% | 25% | 80% |
| 正常 | 5% | 20% | 60% |
| 保守 | 4% | 15% | 40% |
| 防御 | 3% | 10% | 20% |

### 4. TenbaggerScorer (十倍股评分器)

**功能**: 识别成长阶段

**阶段**:
- `S0_潜伏期`: 未启动
- `S1_启动期`: 首板或放量突破 ⭐ 重点关注
- `S2_主升期`: 连续涨停
- `S3_加速期`: 超涨
- `S4_衰退期`: 动能减弱
- `S5_完成期`: 趋势结束

## 🔧 使用指南

### 快速回测

```python
# 使用固定主题模式（推荐，快速）
python scripts/run_bull_market_v6_fast.py

# 完整回测（包含动态主线，较慢）
python scripts/run_bull_market_v6_backtest.py
```

### 策略调用

```python
from core.strategy.bull_market_strategy_v6 import BullMarketStrategyV6

# 初始化（固定主题模式）
strategy = BullMarketStrategyV6(use_dynamic_mainline=False)

# 获取决策
decision = strategy.make_decision(
    as_of_date="2024-09-25",
    candidate_stocks=["002230.XSHE", "300033.XSHE", ...],
)

# 查看结果
print(f"市场类型: {decision.market_type}")
print(f"策略模式: {decision.strategy_mode}")
print(f"买入标的: {decision.buy_targets}")
```

## ⚠️ 注意事项

### 1. 回测速度

- **固定主题模式**: ~30秒完成4个时段回测
- **动态主线模式**: ~5分钟完成（需获取400+概念数据）

### 2. 已知问题

- `TenbaggerScorer.score_stock()` 返回值格式变化，需要使用 `result.stage` 和 `result.score`
- 动态主线识别在某些时段可能无法识别有效主线

### 3. 优化建议

- 在快牛行情中使用固定AI主题效果最佳
- 可根据市场类型动态切换选股模式
- 极端牛市中适当提高换手率
