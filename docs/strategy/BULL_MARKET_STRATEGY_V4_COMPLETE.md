## 三、回测结果

### 3.1 多时段回测汇总

| 时段 | 周收益 | 总收益 | 夏普比率 | 交易次数 | 评价 |
|------|--------|--------|----------|----------|------|
| 2024政策牛 | **128.58%** | 758.01% | 6.12 | 10 | ✅ 优秀 |
| 2024年底 | 7.21% | 33.97% | 0.16 | 55 | ⚠️ 一般 |
| 2020夏季牛 | 8.22% | 39.32% | 0.20 | 13 | ⚠️ 一般 |
| 2019春季牛 | - | -674.96% | -0.88 | 93 | ❌ 亏损 |

### 3.2 结果分析

**优势:**
- 2024年9-10月政策牛市期间表现极佳（周收益128%）
- 涨停因子在快速上涨行情中信号准确

**问题:**
- 2019年春季牛市表现不佳（负收益）
- 最大回撤计算存在bug（显示正数）
- 长时段回测存在数值溢出问题

**原因分析:**
1. 2019年数据特点不同（慢牛）
2. 回测引擎对极端收益处理有问题
3. 参数在不同市场环境下泛化能力有限

## 四、实盘交易规则

### 4.1 买入规则

```
1. 市场状态检测（每日开盘前）
   - ensemble_score >= 30 → 牛市模式（全仓）
   - ensemble_score >= -30 → 混合模式（60%仓位）
   - ensemble_score < -30 → 停止交易

2. 信号筛选
   - 按评分排序，选择score >= 55的股票
   - 最多持有5只，单只不超过20%

3. 买入时机
   - 周频调仓（每周一）
   - 或信号触发当日买入
```

### 4.2 卖出规则

```
止损优先级:
1. 硬止损: 亏损 >= 10% → 立即全仓卖出
2. 软止损: 亏损 >= 8% 且持仓 >= 3天 → 减仓50%
3. 移动止损: 盈利达15%后，从最高点回撤9% → 全仓卖出

止盈优先级:
1. 第一批: 盈利 >= 20% → 减仓50%
2. 第二批: 盈利 >= 30% → 再减仓30%
3. 全止盈: 盈利 >= 40% → 全仓卖出
4. 时间止损: 持仓 >= 20天 → 无论盈亏平仓
```

## 五、接下来一个月的投资建议

### 5.1 市场判断

根据2026-01-12的市场趋势分析：
- 当前趋势得分：约0附近（震荡）
- HMM状态：震荡
- 策略模式：**混合模式**

### 5.2 操作建议

| 项目 | 建议 |
|------|------|
| **仓位** | 50-60%，不建议满仓 |
| **选股方向** | 关注首板启动信号，等待放量突破 |
| **止损** | 严格执行-10%硬止损 |
| **调仓频率** | 周频调仓，避免频繁交易 |

### 5.3 关注板块

1. **政策催化板块** - 等待政策信号
2. **低位放量板块** - 关注首板启动
3. **资金流入板块** - flow_strength > 0.5

### 5.4 风险提示

1. 当前市场处于震荡期，不适合激进策略
2. 等待ensemble_score > 30再加仓
3. 若出现ensemble_score < -30，建议空仓观望
