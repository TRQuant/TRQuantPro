## 🔧 核心技术模块

### 1. 市场类型判断系统（V7.0）

**核心文件**: `core/strategy/market_character_classifier_v7.py`

**判断逻辑**：
```
市场类型 = f(趋势得分, 加速度, 市场宽度, 资金流向, HMM预测)

类型分类：
- 极端牛市: 趋势>50 + 周收益>5% + 市场宽度>60
- 快牛: 趋势>35 + 加速度>2% + 快速牛市信号
- 慢牛: 趋势>20 + HMM预测牛市
- 震荡: 趋势10-20
- 熊市: 趋势<10
```

**关键阈值**（已优化）：
- 快牛阈值: 35分
- 慢牛阈值: 20分
- 极端牛市阈值: 50分
- 周收益触发: 5%

### 2. 多周期共振+HMM系统（Resonance V2）

**核心文件**: `core/resonance_v2/`

**四层架构**：
1. **数据层**: JQData数据获取（指数、行业、个股、资金流向）
2. **特征层**: 多周期特征提取（慢周期60日+快周期10日）
3. **状态层**: HMM状态识别（使用hmmlearn GaussianHMM）
4. **策略层**: 信号生成与仓位管理

**观测变量**（V2增强版）：
- 基础变量：log_return, volatility, trend_strength, turnover_ratio
- **新增变量**：momentum_20d, rsi_deviation, north_flow, breadth_score

**训练参数**（V2优化）：
- 训练窗口：504天 → **252天**（更快响应）
- 测试窗口：63天 → **42天**（更频繁更新）
- 重训练频率：21天 → **10天**（更频繁重训练）

### 3. HMM状态解释修复（2026-01-12）

**问题发现**：
- 原始HMM状态标签与实际市场表现**反转**
- `risk_on`实际对应负收益，`risk_off`实际对应正收益

**修复方案**：
1. ✅ **短期修复**：在使用时交换标签
2. ✅ **根本修复**：修改`_interpret_states`方法，使用波动率反向排序（低波动=risk_on）

**修复后表现**：
| 指标 | 修复前 | 修复后 | 改进 |
|------|--------|--------|------|
| 方向预测准确率 | 39.1% | **57.3%** | +18.2% |
| 收益分化度 | -8.05% | **+8.05%** | 方向正确 |
| Risk-Off有效性 | 21.7% | **58.5%** | +36.8% |
| 综合置信度 | 50.6 | **58.8** | +8.2 |
