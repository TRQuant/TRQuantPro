## 📋 核心原则

1. **基于历史验证**: 所有因子必须从历史10%+高收益案例中提取和验证
2. **理论假设明确**: 每个因子都要有清晰的理论假设和逻辑
3. **避免简单堆砌**: 不能简单堆积聚宽因子库，必须基于验证结果选择
4. **优先已验证因子**: 优先使用从历史案例中提取的已验证因子

## 🔬 已验证因子列表（基于438个10%+案例）

### 1. 20日动量（核心因子，权重1.0）

**理论假设**: 动量驱动假设
- **假设**: 适度上涨趋势（5%~30%）能延续，但过热（>30%）风险高
- **逻辑**: 历史案例显示，20日动量在5%~30%区间的股票，平均收益21.59%，命中率最高
- **验证结果**: 99个动量驱动型案例，平均收益21.59%，有效性⭐⭐⭐⭐⭐
- **最优区间**: 5%~30%（中心值17.5%得分最高）

**评分逻辑**:
```python
if 5.0 <= momentum_20d <= 30.0:
    score = 1.0 - abs(momentum_20d - 17.5) / 12.5  # 距离中心越近得分越高
elif momentum_20d < 5.0:
    score = momentum_20d / 5.0 * 0.5  # 低于5%线性递减
else:
    score = 1.0 - (momentum_20d - 30.0) / 20.0  # 高于30%过热，得分递减
```

### 2. 相对位置（核心因子，权重0.9）

**理论假设**: 低位反弹假设
- **假设**: 相对位置<80%的股票反弹概率高，避免追高
- **逻辑**: 248个低位反弹型案例显示，相对位置在1.2%~55.1%区间的股票，平均收益15.62%
- **验证结果**: 低位反弹型案例占比56.6%，有效性⭐⭐⭐⭐
- **最优区间**: <80%（30%以下得分最高）

**评分逻辑**:
```python
if rel_position <= 80.0:
    if rel_position <= 30.0:
        score = 1.0  # 低位，得分最高
    else:
        score = 1.0 - (rel_position - 30.0) / 50.0 * 0.3  # 30%~80%线性递减
else:
    score = 1.0 - (rel_position - 80.0) / 20.0  # 高于80%高位，得分低
```

### 3. 市值（核心因子，权重0.85）

**理论假设**: 市值弹性假设
- **假设**: 中小市值（30~200亿）弹性大，易被资金推动
- **逻辑**: 166个小市值型案例（<50亿）占比37.9%，平均收益17.47%，弹性明显大于大盘股
- **验证结果**: 小市值案例占比37.9%，有效性⭐⭐⭐⭐
- **最优区间**: 30~200亿（中心值115亿得分最高）

**评分逻辑**:
```python
if 30.0 <= market_cap <= 200.0:
    score = 1.0 - abs(market_cap - 115.0) / 85.0  # 距离中心越近得分越高
elif market_cap < 30.0:
    score = market_cap / 30.0 * 0.7  # 太小风险高
else:
    score = 1.0 - (market_cap - 200.0) / 300.0  # 太大弹性小
```

### 4. 5日动量（确认因子，权重0.75）

**理论假设**: 短期确认假设
- **假设**: 5日动量(-5%~10%)确认短期趋势，避免过热
- **逻辑**: 适度动量（-5%~10%）既能捕捉趋势，又避免追高，历史验证命中率高
- **验证结果**: 短期动量确认，有效性⭐⭐⭐
- **最优区间**: -5%~10%（中心值2.5%得分最高）

**评分逻辑**:
```python
if -5.0 <= momentum_5d <= 10.0:
    score = 1.0 - abs(momentum_5d - 2.5) / 7.5  # 距离中心越近得分越高
elif momentum_5d < -5.0:
    score = (momentum_5d + 10.0) / 5.0 * 0.5  # 过度回调
else:
    score = 1.0 - (momentum_5d - 10.0) / 15.0  # 过热
```

### 5. 换手率（流动性因子，权重0.7）

**理论假设**: 流动性假设
- **假设**: 换手率反映市场关注度和资金流入
- **逻辑**: 高换手率表明市场关注度高，资金流入活跃，有利于价格上涨
- **验证结果**: 流动性因子，有效性⭐⭐⭐
- **最优区间**: 2%~10%（适度换手得分高）

**评分逻辑**:
```python
if 2.0 <= turnover_rate <= 10.0:
    score = 1.0  # 适度换手得分最高
elif turnover_rate < 2.0:
    score = turnover_rate / 2.0 * 0.7  # 流动性不足
else:
    score = 1.0 - (turnover_rate - 10.0) / 20.0  # 过度换手（可能是出货）
```

### 6. ROE（基本面底线，权重0.5）

**理论假设**: 基本面底线假设
- **假设**: ROE>0确保基本面不恶化，避免踩雷
- **逻辑**: 虽然高收益主要来自动量而非价值，但ROE>0是底线，避免基本面恶化股票
- **验证结果**: 基本面筛选，有效性⭐⭐
- **最优区间**: >0（最高10%ROE得满分）

**评分逻辑**:
```python
if roe > 0:
    score = min(1.0, roe / 10.0)  # 最高10%ROE得满分
else:
    score = 0.0  # 负ROE得分0
```

### 7. 净利润增长率（成长性因子，权重0.4）

**理论假设**: 成长性假设
- **假设**: 增长>0是加分项，但非必要条件
- **逻辑**: 优质成长型案例仅占2.5%，说明高收益主要来自动量而非价值，但增长>0是加分项
- **验证结果**: 成长性因子，有效性⭐⭐
- **最优区间**: >0（最高100%增长得满分）

**评分逻辑**:
```python
if growth > 0:
    score = min(1.0, growth / 100.0)  # 最高100%增长得满分
else:
    score = 0.0  # 负增长得分0
```
