# Investment Advisor V4.0 因子架构设计

> **版本**: V2.0  
> **日期**: 2026-01-08  
> **核心原则**: 基于历史验证，不能简单堆砌聚宽因子库

---

## 🎯 因子选择原则

### 核心原则

1. **基于历史验证**: 所有因子必须从历史10%+高收益案例中提取和验证
2. **理论假设明确**: 每个因子都要有清晰的理论假设和逻辑
3. **避免简单堆砌**: 不能简单堆积聚宽因子库，必须基于验证结果选择
4. **优先已验证因子**: 优先使用从历史案例中提取的已验证因子

## 🔄 因子计算逻辑

### 综合得分计算

```python
# 已验证因子得分（100%权重）
validated_score = ValidatedFactorCalculator.calculate_all_validated_factors(codes, date)

# 最终得分（100%已验证因子）
total_score = validated_score
```

**说明**: 不再使用聚宽因子融合，原因：
1. 已验证因子已覆盖主要维度（技术面、基本面、资金面、规模）
2. 聚宽因子与已验证因子存在重叠（momentum、size、ROE等）
3. 聚宽因子未基于历史案例验证，缺乏理论依据
4. 简化系统，减少不确定性

## 📋 因子理论假设汇总

### 已验证因子理论

1. **动量驱动假设**（20日动量）
   - 理论：适度上涨趋势（5%~30%）能延续
   - 验证：99个动量驱动型案例，平均收益21.59%

2. **低位反弹假设**（相对位置）
   - 理论：相对位置<80%的股票反弹概率高
   - 验证：248个低位反弹型案例，平均收益15.62%

3. **市值弹性假设**（市值）
   - 理论：中小市值（30~200亿）弹性大，易被资金推动
   - 验证：166个小市值案例，平均收益17.47%

4. **短期确认假设**（5日动量）
   - 理论：5日动量(-5%~10%)确认短期趋势，避免过热
   - 验证：适度动量区间命中率高

5. **流动性假设**（换手率）
   - 理论：换手率反映市场关注度和资金流入
   - 验证：流动性因子，有效性⭐⭐⭐

6. **基本面底线假设**（ROE）
   - 理论：ROE>0确保基本面不恶化，避免踩雷
   - 验证：基本面筛选，有效性⭐⭐

7. **成长性假设**（净利润增长率）
   - 理论：增长>0是加分项，但非必要条件
   - 验证：成长性因子，有效性⭐⭐

## 🔧 实现细节

### ValidatedFactorCalculator

**文件**: `core/advisor_v4/validated_factor_calculator.py`

**功能**:
- 计算7个已验证因子
- 每个因子都有理论假设和验证结果
- 基于历史案例的最优区间评分
- 输出综合得分（0-100）

### MultiFactorCalculator

**文件**: `core/advisor_v4/multi_factor_calculator.py`

**功能**:
- 使用已验证因子（100%权重）
- 输出最终综合得分（total_score = validated_score）
- 统一管理所有因子计算
