## 功能概述

为了避免回测结果覆盖和支持版本对比，我们在 notebook 中添加了以下功能：

### ✅ 核心功能

1. **版本标签 (VERSION_TAG)**: 为每次回测运行添加标签，避免覆盖旧结果
2. **结果选择器**: 列出所有历史回测结果，显示关键指标
3. **结果比较工具**: 对比多个版本的回测结果，自动分析差异

### 🎯 解决的问题

- ❌ **旧问题**: 相同配置的回测会覆盖旧结果
- ✅ **新方案**: 每次运行都可以保存为新版本，支持历史回溯
- ❌ **旧问题**: 无法方便地对比不同算法版本的效果
- ✅ **新方案**: 一键对比多个版本，自动生成分析报告

## 最佳实践

### 1. 版本命名

#### ✅ 推荐命名方式

| 类型 | 示例 | 说明 |
|------|------|------|
| **语义化版本** | `v1.0`, `v1.1`, `v2.0` | 主版本.次版本 |
| **描述性标签** | `优化参数`, `修复bug`, `添加特征` | 说明改动内容 |
| **日期+描述** | `20260104_优化阈值` | 便于时间追溯 |
| **分支标识** | `dev_test`, `prod_release` | 区分开发/生产 |

#### ❌ 避免的命名

- `test`, `test2`, `test3` - 无法区分具体改动
- `新版本`, `最终版` - 不够具体
- 空标签 (`None`) 仅用于临时测试

### 2. 避免覆盖

#### 核心原则

```python
# ❌ 错误：修改算法后使用缓存
VERSION_TAG = 'v1.1'
USE_CACHE = True  # 会加载v1.0的缓存！

# ✅ 正确：修改算法后强制重新运行
VERSION_TAG = 'v1.1'
USE_CACHE = False  # 创建新记录
```

#### 检查清单

- [ ] 修改算法代码后，设置 `USE_CACHE=False`
- [ ] 为每个重要版本设置有意义的 `VERSION_TAG`
- [ ] 运行后，在结果选择器中验证新版本已保存
- [ ] 定期清理无用的测试版本（通过MongoDB）

### 3. 结果比较

#### 对比策略

| 对比场景 | 建议版本数 | 注意事项 |
|----------|-----------|----------|
| **快速验证** | 2个 | 基准vs新版本 |
| **多次迭代** | 3-4个 | 基准+多个优化版本 |
| **全面分析** | 5+个 | 跨越多个版本的趋势分析 |

#### 关注指标

1. **准确率提升幅度**
   - 提升 > 2%: 显著改进 ✅
   - 提升 < 0.5%: 改进不明显 ⚠️
   - 下降: 需要回滚 ❌

2. **信号数变化**
   - 信号数增加但准确率下降: 阈值过宽
   - 信号数减少但准确率提升: 可能错过机会
   - 找到平衡点

3. **不同时间段的表现**
   - 使用可视化工具查看各时间段准确率
   - 分析哪个时间段改进最明显
   - 避免过拟合某个市场阶段

### 4. 版本管理策略

#### 推荐分支策略

```
baseline (v1.0)
    ├── dev/feature1 (v1.1_test)
    │   └── prod/feature1 (v1.1_release)
    ├── dev/feature2 (v1.2_test)
    │   └── prod/feature2 (v1.2_release)
    └── hotfix/bug1 (v1.0.1_fix)
```

#### 保留策略

| 版本类型 | 保留策略 |
|----------|----------|
| **基准版本** | 永久保留 |
| **正式发布版本** | 永久保留 |
| **测试版本** | 验证后可删除 |
| **失败尝试** | 记录后删除 |

### 版本标签更新逻辑

```python
# 1. 运行回测
phase1_result = run_phase1_backtest(sample_interval=10, use_cache=False)

# 2. 查询最新结果
latest_results = storage.query_backtest_results(
    backtest_type='signal_phase1',
    limit=1,
    sort_by='created_at',
    sort_order=-1
)

# 3. 更新版本标签
if latest_results:
    from bson import ObjectId
    result_id = latest_results[0]['_id']
    storage.db[storage.BACKTEST_COLLECTION].update_one(
        {'_id': ObjectId(result_id)},
        {'$set': {'version_tag': VERSION_TAG}}
    )
```

### 缓存策略

#### 缓存匹配条件

缓存查找基于以下字段：
1. `backtest_type`: 回测类型
2. `algorithm_version`: 算法代码哈希
3. `config_hash`: 配置参数哈希

#### 缓存流程

```
                   USE_CACHE=True
                         │
                         ↓
        ┌────────────────────────────────┐
        │ 查询缓存（匹配3个字段）        │
        └────────────────────────────────┘
                    │       │
          找到缓存  │       │  未找到缓存
                    ↓       ↓
            ┌──────────┐   ┌──────────┐
            │ 加载缓存 │   │ 运行回测 │
            └──────────┘   └──────────┘
                    │           │
                    ↓           ↓
                 使用结果    保存新结果
```

### 结果比较算法

```python
def compare_versions(result_ids):
    comparison_data = []
    
    for result_id in result_ids:
        doc = storage.db[BACKTEST_COLLECTION].find_one({'_id': ObjectId(result_id)})
        summary = doc.get('summary', {})
        
        comparison_data.append({
            'ID': str(doc['_id'])[:8] + '...',
            'version_tag': doc.get('version_tag', '未命名'),
            'created_at': doc.get('created_at', 'N/A')[:19],
            'total_signals': summary.get('total_signals', 0),
            'accuracy_5d': summary.get('accuracy_5d', 0),
            'accuracy_20d': summary.get('accuracy_20d', 0),
            # ...
        })
    
    # 分析最佳/最差版本
    for metric in ['accuracy_5d', 'accuracy_20d', ...]:
        values = [row[metric] for row in comparison_data]
        best_idx = values.index(max(values))
        worst_idx = values.index(min(values))
        # ...
    
    return comparison_data
```

### B. 故障排除

#### 问题1: 版本标签未更新

**症状**: 运行后，结果选择器显示版本标签为 `None`

**原因**: `VERSION_TAG` 设置后没有生效

**解决**:
```python
# 手动更新
from bson import ObjectId
storage.db[storage.BACKTEST_COLLECTION].update_one(
    {'_id': ObjectId('结果ID')},
    {'$set': {'version_tag': '期望的标签'}}
)
```

#### 问题2: 结果被覆盖

**症状**: 新运行的结果覆盖了旧结果

**原因**: `USE_CACHE=True` 且算法版本和配置未变

**解决**:
- 设置 `USE_CACHE=False`
- 或修改配置参数

#### 问题3: 对比工具无输出

**症状**: 运行Cell 23后没有对比表格

**原因**: `RESULT_IDS_TO_COMPARE` 为空或ID不正确

**解决**:
- 先运行 Cell 22 获取正确的ID
- 复制粘贴ID到 `RESULT_IDS_TO_COMPARE`
- 确保ID格式正确（24位十六进制字符串）
