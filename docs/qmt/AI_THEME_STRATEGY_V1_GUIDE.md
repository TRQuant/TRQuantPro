# TRQuant AI Theme Strategy V1.0 - QMT使用指南

## 策略概述

**策略名称**: TRQuant AI Theme Strategy V1.0
**策略类型**: AI主题动量策略
**适用平台**: QMT (QuantConnect Mini Terminal)
**策略文件**: `strategies/qmt/TRQuant_AI_Theme_V1.py`

## 策略特点

1. **固定AI主题股票池**: 15只经过筛选的AI核心股票
2. **周频调仓**: 每5个交易日调仓一次
3. **因子评分选股**: 基于4个价量因子的综合评分
4. **完整风控体系**: 止损止盈 + 移动止损 + 轮动卖出
5. **华泰证券标准佣金**: 符合实盘交易成本

## 因子体系

### 因子定义

| 因子 | 权重(分值) | 最优区间 | 说明 |
|------|------------|----------|------|
| 20日动量 | 40分 | 5%~30% | 中期趋势强度 |
| 相对位置 | 30分 | 40%~70% | 价格在20日区间的位置 |
| 5日动量 | 20分 | -2%~8% | 短期趋势确认 |
| 量比 | 10分 | 1.2~2.0 | 近5日/前5日成交量比 |

### 评分逻辑

1. **20日动量评分**:
   - 最优区间(5%~30%): 40 - |m20 - 17.5| * 1.6
   - 区间外: max(0, 20 - |m20 - 17.5|)

2. **相对位置评分**:
   - 最优区间(40%~70%): 满分30分
   - 低于40%: 20 + rel_pos / 4
   - 高于70%: max(0, 30 - (rel_pos - 70) / 2)

3. **5日动量评分**:
   - 最优区间(-2%~8%): 20 - |m5 - 3| * 2
   - 区间外: max(0, 10 - |m5 - 3|)

4. **量比评分**:
   - 最优区间(1.2~2.0): 满分10分
   - 过高(>2.0): max(0, 10 - (vol_ratio - 2.0) * 5)
   - 过低(<1.2): max(0, vol_ratio * 8)

5. **信号加成**:
   - 买入信号: +10分
   - 卖出信号: -20分

## 信号生成

### 买入信号

价格突破20日最高价（动量突破）:
```
if yesterday_high > max(high_20d[:-2]):
    buy_signal = 1
```

### 卖出信号

价格跌破60日均价（趋势破坏）:
```
if yesterday_high < mean(close_60d[:-2]):
    sell_signal = 1
```

## 交易流程

### 每日检查（风控）

1. 检查止损条件: P&L <= -8%
2. 检查止盈条件: P&L >= +30%
3. 检查移动止损: 盈利15%后从最高点回撤9%

### 周频调仓

1. **生成信号**: 计算买卖信号
2. **因子评分**: 计算4个因子评分
3. **选股排序**: 按总分降序排列
4. **轮动卖出**: 卖出不在Top10的持仓
5. **信号卖出**: 卖出有卖出信号的持仓
6. **买入新股**: 等权重买入Top10新股票

## 在QMT中使用

### 步骤1: 复制策略文件

将 `strategies/qmt/TRQuant_AI_Theme_V1.py` 复制到QMT策略目录:
```
C:\Users\{用户名}\迅投极速交易终端QMT\strategies\
```

### 步骤2: 配置回测参数

- **起始日期**: 2025-12-13（近一个月）
- **结束日期**: 2026-01-12
- **初始资金**: 1,000,000
- **数据频率**: 日线
- **回测模式**: 柱回测

### 步骤3: 运行回测

1. 打开QMT客户端
2. 进入"回测管理"
3. 选择策略文件
4. 设置回测参数
5. 点击"开始回测"

### 步骤4: 查看结果

回测结束后可查看:
- 收益曲线
- 交易明细
- 持仓变化
- 风险指标

## 注意事项

### 数据获取

- 使用 `get_history_data(days, '1d', field, 0)` 获取全部股票数据
- 参数 `0` 返回dict格式，包含所有股票
- 避免使用参数 `3`，可能只返回少数股票

### 编码问题

- 策略文件必须使用GBK编码（`#coding:gbk`）
- 注释使用英文，避免中文导致的编码问题

### 性能优化

- 股票池固定为15只，数据获取效率高
- 因子计算简单高效，仅使用价量数据
- 无需获取基本面数据，避免数据延迟

### 实盘注意

- 实盘交易前需要连接券商API
- 佣金参数根据实际券商调整
- 建议先在模拟盘验证策略表现
