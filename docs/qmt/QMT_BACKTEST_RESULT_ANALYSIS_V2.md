## 🔍 问题分析

### 1. 因子筛选过于严格

**问题**：
- 只有0.23%的股票通过筛选
- 导致选股范围太小，缺乏多样性
- 某些调仓只有1-5只股票可选

**原因**：
- `MIN_MOMENTUM_20D = 0.0%`：仍然过滤掉大部分股票
- `MIN_MARKET_CAP = 30.0`：可能过于严格
- `MAX_MARKET_CAP = 200.0`：可能过于严格
- 基本面数据获取失败，使用fallback，可能不准确

### 2. 交易成本过高

**问题**：
- 总交易费用：7,356.78
- 占总资产的0.79%
- 每周调仓导致频繁交易

**计算**：
- 平均每次调仓费用：7,356.78 / 12 = 613.07
- 如果回报率只有-6.37%，交易成本占亏损的11.6%

### 3. 持仓表现不佳

**最终持仓P&L**：
- 002463.SZ: +4.48% ✅
- 601138.SH: +6.06% ✅
- 300456.SZ: +10.98% ✅
- 601318.SH: -1.36% ❌
- 300102.SZ: -2.54% ❌
- 其他持仓：大部分亏损

**问题**：
- 虽然有盈利股票，但整体组合表现不佳
- 可能因为选股范围太小，缺乏分散性

### 4. 市场环境因素

**回测期间**：2025-10-13 至 2025-12-29
- 可能是市场调整期或熊市
- 策略在不利市场环境下表现不佳

## 🎯 优化建议

### 1. 放宽因子筛选阈值（优先级：最高）

**当前阈值**：
```python
MIN_MOMENTUM_20D = 0.0%      # 仍然太严格
MIN_MARKET_CAP = 30.0       # 可能太严格
MAX_MARKET_CAP = 200.0      # 可能太严格
MIN_ROE = 0.0%              # 合理
```

**建议调整**：
```python
MIN_MOMENTUM_20D = -5.0%    # 允许轻微负动量（已在fallback中使用）
MIN_MARKET_CAP = 20.0       # 降低到20亿
MAX_MARKET_CAP = 300.0      # 提高到300亿
MIN_ROE = -5.0%             # 允许轻微负ROE（特殊情况）
```

**预期效果**：
- 选股通过率：0.23% → 1-2%（5-10倍提升）
- 选股多样性增加
- 更好的分散性

### 2. 调整调仓频率（优先级：高）

**当前**：每周调仓（5个交易日）

**建议**：
- **方案A**：每2周调仓（10个交易日）
- **方案B**：每月调仓（20个交易日）
- **方案C**：动态调仓（只有当新股票分数显著高于持仓股票时才调仓）

**预期效果**：
- 交易成本降低50-75%
- 减少过度交易
- 给持仓更多时间表现

### 3. 优化止损止盈逻辑（优先级：高）

**当前**：仅20MA止损（5%缓冲）

**建议**：
- **动态止损**：基于ATR设置止损距离（如2倍ATR）
- **分批止盈**：达到目标收益（如10%）后分批卖出
- **持仓周期**：最小持仓周期（如至少持有2周）

**预期效果**：
- 减少亏损持仓的持有时间
- 锁定盈利持仓的收益
- 提高整体回报率

### 4. 修复基本面数据获取（优先级：中）

**当前**：`get_fundamental_data_qmt`失败，使用fallback

**建议**：
- 检查QMT的`get_financial_data`正确用法
- 确保ROE、growth等因子准确
- 如果无法获取，考虑移除或降低这些因子的权重

**预期效果**：
- 因子计算更准确
- 选股质量提升

### 5. 添加市场环境检测（优先级：中）

**建议**：
- 检测市场趋势（牛市/熊市/震荡）
- 在熊市时降低仓位或暂停交易
- 在牛市时增加仓位

**预期效果**：
- 避免在不利市场环境下交易
- 提高策略适应性
