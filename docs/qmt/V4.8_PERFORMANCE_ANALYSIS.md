## 💡 优化建议（基于回测结果）

### 1. 渐进式轮动（优先级：高）

**问题**: 当前100%轮动，可能错过持续上涨的股票

**方案**:
```python
# 部分保留机制
def should_keep_stock(stock, current_rank, target_stocks):
    """判断是否保留股票"""
    # 如果股票在Top 15（而非Top 10），且当前盈利>5%，考虑保留
    if stock in target_stocks[:15] and current_pnl > 5.0:
        return True
    return False
```

**预期效果**:
- 减少不必要的轮动
- 保留持续上涨的股票
- 降低交易成本

### 2. 动态止损止盈（优先级：高）

**问题**: 当前只有固定止损，没有止盈

**方案**:
```python
# 动态止损止盈
def check_dynamic_exit(stock, entry_price, current_price, ma20):
    """动态退出检查"""
    pnl_pct = (current_price - entry_price) / entry_price * 100
    
    # 止损：-8% 或跌破20MA
    if pnl_pct < -8.0 or current_price < ma20 * 0.97:
        return "SELL_STOP_LOSS"
    
    # 止盈：+15%后回撤至+10%
    if pnl_pct > 15.0:
        if pnl_pct < 10.0:
            return "SELL_PROFIT_TAKING"
    
    # 止盈：+20%后回撤至+15%
    if pnl_pct > 20.0:
        if pnl_pct < 15.0:
            return "SELL_PROFIT_TAKING"
    
    return "HOLD"
```

**预期效果**:
- 保护利润（止盈）
- 控制亏损（止损）
- 让利润奔跑（动态止盈）

### 3. 选股质量提升（优先级：中）

- 提高整体收益

### 5. 持仓保留机制（优先级：中）

**问题**: 100%轮动，可能错过持续上涨的股票

**方案**:

# 如果股票仍在Top 15且盈利>5%，保留50%仓位
if stock in target_stocks[:15] and current_pnl > 5.0:
