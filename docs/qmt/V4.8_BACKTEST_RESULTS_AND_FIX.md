## ⚠️ 发现的关键问题

### 问题：大量选中股票无法获取开盘价

**现象**:
```
[Buy Warning] 300001.SZ: Not in current_prices (skipping)
[Buy Warning] 605111.SH: Not in current_prices (skipping)
[Buy Warning] 600183.SH: Not in current_prices (skipping)
...
```

**统计**:
- **Rebalance #1**: 10只目标股票，只有 **1只** 成功买入（10%）
- **Rebalance #2**: 10只目标股票，只有 **4只** 成功买入（40%）
- **Rebalance #3**: 8只目标股票，只有 **1只** 成功买入（12.5%）
- **Rebalance #4**: 7只目标股票，只有 **2只** 成功买入（28.6%）
- **Rebalance #5**: 5只目标股票，只有 **2只** 成功买入（40%）
- **Rebalance #6**: 10只目标股票，只有 **2只** 成功买入（20%）

**平均买入成功率**: 约 **25%**（大部分股票无法买入）

### 根本原因

1. **QMT API限制**: `get_history_data(1, '1d', 'open', 0)` 可能只返回部分股票的开盘价数据
2. **停牌/新上市**: 某些股票可能当天停牌或新上市，没有开盘价数据
3. **缓存问题**: 磁盘缓存可能保存了不完整的数据，导致后续调用也缺少数据

### 影响

- ❌ **仓位不足**: 只能买入25%的选中股票，导致仓位利用率低
- ❌ **分散化不足**: 实际持仓数量远低于目标（MAX_STOCKS=10）
- ❌ **策略效果打折**: 虽然选出了优质股票，但无法全部买入

---

## 🔧 修复方案（V4.8 13:08:00）

### 方案：使用收盘价作为开盘价的备用

**逻辑**:
1. 首先尝试获取 `open` 价格
2. 对于缺失 `open` 价格的股票，使用 `close_22` 中的最新收盘价作为备用
3. 收盘价作为开盘价的近似值是合理的（在同一天或下一个交易日）

**代码改动**:
```python
# Get current price for trading
current_prices = {}
try:
    # First try to get open prices
    open_prices = get_all_stock_data(ContextInfo, target_stocks, 'open', 1, ...)
    if open_prices:
        current_prices.update(open_prices)
    
    # Fallback: Use close price from close_22 for stocks missing open data
    missing_stocks = [s for s in target_stocks if s not in current_prices]
    if missing_stocks:
        for stock in missing_stocks:
            if stock in close_22 and len(close_22[stock]) > 0:
                close_price = close_22[stock][-1]
                if close_price > 0:
                    current_prices[stock] = [close_price]
except Exception as e:
    # Additional fallback in exception handler
    ...
```

### 预期效果

- ✅ **买入成功率**: 从 25% 提升到 **90%+**（大部分股票都有收盘价数据）
- ✅ **仓位利用率**: 接近 100%（能够买入所有选中股票）
- ✅ **分散化**: 实际持仓数量接近目标（MAX_STOCKS=10）
