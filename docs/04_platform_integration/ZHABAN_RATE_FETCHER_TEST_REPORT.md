## ⚠️ 注意事项

1. **历史数据限制**: AKShare接口只能获取"近期"历史数据，具体范围可能因数据源而异
2. **请求频率**: 批量获取时建议设置合理的请求间隔（0.3-0.5秒）
3. **数据缺失**: 对于无法获取的历史数据，工具会自动使用估算值（15%）
4. **交易日过滤**: 批量获取时，工具会简单过滤周末，但更准确的应该使用交易日历
