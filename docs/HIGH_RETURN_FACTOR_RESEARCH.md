## 7. 风险提示

### 7.1 策略局限性

1. **高收益伴随高风险**: 10%+的收益目标意味着较大的波动性
2. **样本偏差**: 分析基于历史数据，未来不一定重复
3. **市场环境依赖**: 牛市/震荡市效果不同
4. **流动性风险**: 小市值股票流动性较差

### 7.2 使用建议

1. **控制仓位**: 单只股票仓位不超过10%
2. **分散投资**: 同时持有多种模式的股票
3. **设置止损**: 建议-8%止损
4. **动态调整**: 根据市场环境调整模式权重

## 10. 过拟合问题与稳健策略

### 10.1 问题发现

在测试集验证中发现严重过拟合：

| 指标 | 训练集 | 测试集 | 差异 |
|------|--------|--------|------|
| 平均收益 | 18.62% | **-0.15%** | -18.77% |
| 15%+命中率 | 51.2% | 3.7% | -47.5% |

**原因**: 训练集是"事后诸葛亮"（选已涨股票），测试集是"事前预测"（预测未来）。

### 10.2 稳健策略设计

放弃追求10%+收益，转向稳定超额收益：

```python
ROBUST_PARAMS = {
    'market_cap': (50, 200),     # 中等市值，排除小盘高波动
    'momentum_20d': (3, 15),      # 温和上涨，不追高
    'momentum_5d': (-5, 5),       # 近期不过热
    'rel_position_max': 65,       # 中低位入场
    'roe_min': 0,                 # 基本面底线
    'stop_loss': -0.05,           # 5%止损
    'take_profit': 0.08,          # 8%止盈
}
```

### 10.3 测试集验证结果

| 指标 | 原始策略 | 稳健策略 | 改进 |
|------|---------|---------|------|
| 平均5日收益 | -0.15% | **+0.58%** | +0.73% ✅ |
| 超额收益 | -0.15% | **+0.36%** | +0.51% ✅ |
| 盈利率 | 46.8% | **58.1%** | +11.3% ✅ |
| 夏普比率 | -0.035 | **0.109** | +0.144 ✅ |

### 10.4 结论

1. **10%+周收益不现实**: 历史案例存在幸存者偏差
2. **稳健策略有效**: 降低预期+风控反而获得正收益
3. **合理预期**: 周收益2%~5%、盈利率55%~60%
