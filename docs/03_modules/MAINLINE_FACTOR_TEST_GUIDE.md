## 🖥️ GUI界面说明

### 界面布局

1. **顶部控制面板**
   - 行业代码输入框（如 801010）
   - 日期选择（默认今天）
   - 期限选择（short/medium/long）
   - 计算按钮

2. **结果展示区域**
   - 综合得分（大字体，颜色编码）
   - 各因子得分表格
   - 详细数据（JSON格式）

3. **状态栏**
   - 显示当前操作状态
   - 显示进度信息

### 使用步骤

1. **选择参数**
   - 输入或选择行业代码
   - 选择日期（默认今天）
   - 选择期限（推荐medium）

2. **点击计算**
   - 点击"🚀 计算因子组合得分"按钮
   - 观察进度条
   - 等待计算完成

3. **查看结果**
   - 综合得分（0-100分）
   - 各因子得分（表格形式）
   - 详细数据（JSON格式）

## 📈 结果解读

### 综合得分

- **0-100分**: 综合得分范围
- **>=70分**: 优秀（绿色显示）✅
- **50-70分**: 良好（黄色显示）⚠️
- **<50分**: 一般（红色显示）❌

### 因子得分

5大类因子及其权重（medium期限）：

| 因子类别 | 权重 | 说明 |
|---------|------|------|
| 宏观因子 | 20% | PMI、M2增长率等 |
| 资金流因子 | 30% | 主力资金、北向资金（权重最高） |
| 行业景气因子 | 25% | 营收增长、利润增长、ROE等 |
| 技术动量因子 | 15% | Alpha191因子、RSI等技术指标 |
| 市场情绪因子 | 10% | 新闻、龙虎榜等 |

## 🐛 常见问题

### Q1: 导入错误

**错误**: `ImportError: cannot import name 'MainlinePredictionFactorCombination'`

**解决**:
1. 确认 `core/mainline/mainline_factor_combination.py` 文件存在
2. 检查Python路径是否正确
3. 确保在项目根目录运行

### Q2: JQData认证失败

**错误**: `JQData认证失败`

**解决**:
1. 检查 `config/jqdata_config.json` 文件
2. 确认账号密码正确
3. 确认账号有相应权限（需要正式账号）

### Q3: 无法获取行业股票

**错误**: `无法获取行业股票列表`

**解决**:
1. 检查行业代码是否正确
2. 确认JQData账号有获取行业数据的权限
3. 尝试使用其他行业代码

### Q4: GUI无法启动

**错误**: PyQt6相关错误

**解决**:
```bash
pip install PyQt6
```

如果仍然有问题，可以尝试命令行测试：
```bash
python tests/test_mainline_factor_simple.py
```
