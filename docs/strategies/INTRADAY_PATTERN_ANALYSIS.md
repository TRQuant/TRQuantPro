## 走势模式分类

### 1. 涨停-开板-再涨停模式

**特征**：
- 首次涨停后开板
- 开板期间回调
- 再次涨停并封板

**市场含义**：
1. **资金博弈激烈**：多空双方分歧较大
2. **承接力强**：开板后能再次涨停，说明买盘力量较强
3. **换手充分**：开板期间完成换手，有利于后续上涨
4. **风险提示**：如果开板次数过多或回调幅度过大，可能封板不稳

**操作建议**：
- 如果回调幅度<3%且开板次数≤2次：封板较稳，可考虑持有
- 如果回调幅度>5%或开板次数>3次：封板不稳，需谨慎
- 关注最后封板时间：越早封板，封板越稳

### 2. 直接涨停模式

**特征**：
- 一次涨停后封板，未开板

**市场含义**：
1. **买盘强劲**：涨停后买盘持续，无抛压
2. **封板坚决**：资金态度明确，看好后市
3. **换手不足**：可能缺乏充分换手，后续可能面临抛压

**操作建议**：
- 封板较稳，但需关注次日开盘表现
- 如果次日高开，可能继续上涨
- 如果次日低开，可能面临回调

### 3. 接近涨停-回调-再涨停模式（省广集团的情况）

**特征**：
- 早盘接近涨停（涨跌幅9%-9.5%）
- 盘中回调
- 随后涨停并封板

**市场含义**：
1. **早盘试探**：资金早盘试探涨停，测试抛压
2. **洗盘充分**：回调期间完成洗盘和换手
3. **资金认可**：回调后资金继续买入，最终涨停
4. **封板较稳**：回调后涨停，说明买盘力量强

**操作建议**：
- 如果回调幅度<5%且回调时间短：封板较稳，可考虑持有
- 关注回调期间的成交量：放量回调需警惕
- 关注涨停时间：越早涨停，封板越稳

### 4. 涨停后开板模式

**特征**：
- 涨停后开板，未再涨停

**市场含义**：
1. **封板不稳**：涨停后遭遇抛压
2. **资金分歧**：多空双方分歧较大
3. **风险较高**：可能面临回调

**操作建议**：
- 谨慎持有，关注后续走势
- 如果回调幅度>5%，建议减仓
- 关注成交量：放量开板需警惕

## 分析方法

### 1. 数据获取

使用AKShare获取分时数据：
```python
import akshare as ak

minute_data = ak.stock_zh_a_hist_min_em(
    symbol="002400",
    start_date="20260114",
    end_date="20260114",
    period="1",  # 1分钟
    adjust=""
)
```

### 2. 涨停判断标准

- **涨停价**：前收盘价 × 1.1（深市/沪市）或 × 1.3（北交所）
- **涨停判断**：收盘价 >= 涨停价 × 0.995（允许0.5%误差）
- **接近涨停**：涨跌幅 >= 9.0% 且 < 9.5%

### 3. 关键指标

- **涨停次数**：盘中涨停的次数
- **开板次数**：涨停后开板的次数
- **回调幅度**：开板期间的最大回调百分比
- **封板时间**：最后涨停的时间
- **封板持续时间**：最后涨停到收盘的持续时间

### 4. 走势模式判断

根据涨停次数和开板次数的组合判断走势模式：
- `limit_up_open_limit_up`: 涨停-开板-再涨停
- `direct_limit_up`: 直接涨停
- `limit_up_then_open`: 涨停后开板
- `open_then_limit_up`: 开板后涨停

## 在陈小群战法中的应用

### 1. 首板卡位术

**适用场景**：启动期（10-30只涨停）

**分析要点**：
- 早盘是否快速接近涨停（9:30-9:35）
- 回调幅度是否<3%
- 是否在早盘涨停（9:35前）
- 封板是否稳定

**操作建议**：
- 如果早盘快速接近涨停且回调小：可考虑早盘介入
- 如果回调幅度>5%：谨慎，可能封板不稳

### 2. 龙头战法

**适用场景**：加速期（30-60只涨停）

**分析要点**：
- 是否出现涨停-开板-再涨停模式
- 开板次数和回调幅度
- 封板时间和持续时间
- 成交量变化

**操作建议**：
- 如果开板次数≤2次且回调<3%：封板较稳，可持有
- 如果开板次数>3次或回调>5%：封板不稳，需谨慎

### 3. 逐步减仓

**适用场景**：过热期（>60只涨停）

**分析要点**：
- 封板是否稳定
- 是否出现多次开板
- 回调幅度是否增大

**操作建议**：
- 如果出现多次开板或回调增大：考虑减仓
- 如果封板稳定：可持有但需关注次日表现
