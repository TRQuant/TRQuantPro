# 回报率改进方案

> **当前回报率**: 3.14% (6个交易日)  
> **目标回报率**: 20%+ (6个交易日)  
> **创建时间**: 2026-01-15

---

## 📊 当前问题分析

### 1. 止损执行不及时
- **问题**: 快意电梯-16.42%才止损，远超-8%止损线
- **原因**: 止损检查可能没有每天执行，或者价格数据获取失败
- **影响**: 亏损放大，影响整体回报率

### 2. 选股质量不够高
- **问题**: 所有股票都是首板（连板数=1），没有抓住二板、三板的龙头机会
- **原因**: 选股逻辑优先选择了首板股票，而不是连板股票
- **影响**: 首板10%仓位，二板50%仓位，三板40%仓位，如果抓住二板龙头，回报率会大幅提升

### 3. 仓位分配不合理
- **问题**: 快意电梯仓位较大（49.93%），亏损影响更大
- **原因**: 首板应该都是10%仓位，但实际仓位不一致
- **影响**: 亏损股票仓位大，盈利股票仓位小，影响整体回报率

### 4. 卖出时机不够精准
- **问题**: 锋龙股份+32.67%才止盈，但实际+17%就卖出了
- **原因**: 止盈检查逻辑可能有问题
- **影响**: 没有充分享受主升浪

## 🔧 改进方案

### 1. 严格执行止损（-8%立即止损）

**问题**: 快意电梯-16.42%才止损

**解决方案**:
1. 确保每天都能获取价格数据（即使没有新的市场数据）
2. 确保止损检查每天执行
3. 如果价格数据获取失败，使用持仓成本作为价格（但记录警告）
4. 增加提前止损机制：如果连续2天未涨停且亏损超过-5%，提前止损

**代码实现**:
```python
# 在_check_exits方法中
# 1. 确保价格数据获取成功
if not price_info:
    # 如果价格数据获取失败，使用持仓成本（但记录警告）
    logger.warning(f"{code} 价格数据获取失败，使用持仓成本")
    current_price = pos['cost']
else:
    current_price = price_info.get('close', pos['cost'])

# 2. 严格执行止损
if pnl_pct <= self.config.stop_loss_pct:
    exit_reason = f'止损({pnl_pct*100:.1f}%)'
# 3. 提前止损
elif days_held >= 2 and pnl_pct <= -0.05:
    exit_reason = f'提前止损({pnl_pct*100:.1f}%，连续下跌)'
```

### 2. 优先选择连板数更高的股票（二板、三板）

**问题**: 所有股票都是首板，没有抓住二板、三板的龙头机会

**解决方案**:
1. 优先选择连板数>=2的股票（龙头战法）
2. 如果没有连板股票，再选择首板股票（首板卡位术）
3. 只选择最强题材的龙头股票

**代码实现**:
```python
# 在_process_daily_trading方法中
# 1. 优先选择连板股票
dragon_stocks = select_dragon_stocks(...)  # 连板数>=2
first_board_stocks = select_first_board_stocks(...)  # 连板数=1

# 2. 合并选股结果，优先连板股票
if dragon_stocks:
    selected_stocks = dragon_stocks[:2]  # 最多2只最强龙头
elif first_board_stocks:
    selected_stocks = first_board_stocks[:3]  # 最多3只首板
```

### 3. 优化仓位分配（最强龙头重仓）

**问题**: 快意电梯仓位较大，亏损影响更大

**解决方案**:
1. 首板严格10%仓位
2. 二板50%主攻仓
3. 三板40%加仓仓（总仓位90%）
4. 优先重仓最强龙头

**代码实现**:
```python
# 在_process_daily_trading方法中
# 根据连板数计算目标仓位
target_stock_position = self._calculate_sanbanfu_position(board_count, current_position_pct)
# 首板10%，二板50%，三板40%
```

### 4. 优化卖出时机（提前识别风险信号）

**问题**: 卖出时机不够精准

**解决方案**:
1. 达到+30%立即止盈
2. 移动止盈：从最高点回撤-10%止盈
3. 如果连续2天未涨停，考虑减仓或卖出

**代码实现**:
```python
# 在_check_exits方法中
# 1. 达到+30%立即止盈
if pnl_pct >= 0.30:
    exit_reason = f'止盈({pnl_pct*100:.1f}%)'
# 2. 移动止盈
elif pnl_pct >= 0.20:
    drawdown_from_high = (current_price - max_price) / max_price
    if drawdown_from_high <= -0.10:
        exit_reason = f'移动止盈({pnl_pct*100:.1f}%，从最高点回撤{drawdown_from_high*100:.1f}%)'
```
