### 2. 筛选首板股票

```python
import jqdatasdk as jq
import akshare as ak

# 获取涨停板数据
limit_up_data = ak.stock_zt_pool_em(date=today)

# 筛选符合首板条件的股票
candidates = []
for stock in limit_up_data.itertuples():
    code = stock.代码
    name = stock.名称
    
    try:
        # 检查流通市值
        security_info = jq.get_security_info(code)
        circulating_cap = security_info.get('circulating_cap', 0)
        
        # 检查是否早盘涨停（需要分时数据）
        price_1m = jq.get_price(code, count=20, end_date=today, frequency='1m')
        
        # 检查封单量
        current_data = jq.get_current_data([code])
        buy1_vol = current_data[code].buy1_vol
        
        # 筛选条件
        if (circulating_cap < 30 * 100000000 and  # 流通市值<30亿
            buy1_vol > circulating_cap * 0.02):    # 封单量>2%
            candidates.append({
                'code': code,
                'name': name,
                'circulating_cap': circulating_cap,
                'buy1_vol': buy1_vol
            })
    except:
        continue

print(f"符合首板条件的股票: {len(candidates)}只")
for candidate in candidates[:10]:
    print(f"  - {candidate['name']} ({candidate['code']})")
```

### 3. 验证板块效应

```python
# 获取板块内涨停股票数量
def check_board_effect(code, today):
    try:
        # 获取股票所属板块
        industry = jq.get_industry(code, date=today)
        industry_stocks = jq.get_industry_stocks(industry, date=today)
        
        # 统计板块内涨停股票数量
        limit_up_count = 0
        for stock in industry_stocks[:50]:  # 限制数量
            try:
                price_data = jq.get_price(stock, count=1, end_date=today, frequency='daily')
                if not price_data.empty:
                    close = price_data['close'].iloc[0]
                    high_limit = price_data['high_limit'].iloc[0]
                    if close >= high_limit * 0.995:
                        limit_up_count += 1
            except:
                continue
        
        return limit_up_count >= 3  # 板块内至少3只涨停
    except:
        return False

# 检查板块效应
if check_board_effect(code, today):
    print("✅ 板块效应确认")
else:
    print("❌ 板块效应不足")
```

### 缺点 ⚠️

1. **高风险高收益**：需要极强的执行力和纪律性
2. **市场环境依赖**：在退潮期效果差
3. **不适合所有人**：需要丰富的实战经验
4. **资金要求**：需要足够的资金才能带动跟风
5. **三板后风险高**：100%仓位风险极高

### 是否有道理

✅ **非常有道理**，原因：

1. **情绪周期是A股市场核心特征**
   - 情绪周期是A股市场的重要特征
   - 不同周期适合不同策略，可以提高成功率
   - 退潮期空仓可以避免大部分亏损

2. **龙头战法逻辑清晰**
   - 龙头股通常涨幅最大、持续时间最长
   - 聚焦总龙头可以提高成功率
   - 重仓持有可以享受主升浪收益

3. **三阶段仓位管理合理**
   - 首板试错（10%）控制风险
   - 二板确认（50%）享受收益
   - 三板加速（40%）最大化收益

4. **选股"三高"标准有效**
   - 高辨识度可以吸引更多资金
   - 高资金可以推动股价上涨
   - 高联动可以降低个股风险
