## 📋 项目概述

基于南大光电等科技领域高成长股案例研究，优化十倍股早期识别系统，解决V2版本全部否决的问题，使系统能够有效识别潜在十倍股。

## 🎯 核心成果

### 1. 案例研究知识库

**典型十倍股案例分析**:
- 南大光电(300346): 2019-2021涨幅10倍+
- 卓胜微(300782): 2019-2021涨幅13倍+
- 斯达半导(603290): 2020-2021涨幅20倍+

**十倍股早期核心特征**:
| 指标 | 典型值 | 说明 |
|------|--------|------|
| 市值 | <100亿 | 小市值空间大 |
| 营收增速 | >25% | 高成长性 |
| 利润增速 | >30% | 盈利能力提升 |
| 毛利率 | >30% | 高附加值 |
| ROE | >5% | 早期可较低 |
| 研发投入 | >5% | 技术壁垒 |

### 2. 系统优化（V2→V3）

**L1早期结构信号配置**（核心改进）:

| V2配置 | V3配置 |
|--------|--------|
| 收入加速(0.25) | 营收增长(0.20) |
| 利润拐点(0.20) | 利润增长(0.20) |
| 毛利率改善(0.15) | 收入加速(0.15) |
| 资本开支强度(0.15) | 毛利率水平(0.15) |
| 研发强度(0.15) | ROE水平(0.15) |
| 产业事件(0.10) | 小市值加成(0.15) |

**阈值调整**:
| 项目 | V2 | V3 |
|------|-----|-----|
| L1通过阈值 | 50分 | 40分 |
| L2通过阈值 | 65分 | 50分 |
| S+等级阈值 | 85分 | 80分 |
| A等级阈值 | 65分 | 58分 |

**L0硬过滤修复**:
- 流动性检查：使用`turnover_ratio >= 0.1%`替代缺失的`avg_turnover`
- 数据获取：正确设置`avg_turnover = turnover_ratio / 100`
