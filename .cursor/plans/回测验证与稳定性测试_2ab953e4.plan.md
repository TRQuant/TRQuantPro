# 回测验证与稳定性测试计划

## 目标

建立全面的回测验证体系，验证已验证因子策略在不同市场环境下的表现，评估策略的稳定性和可靠性。

---

## Phase 0: 半年数据预加载与并行回测（优先执行）

### 0.1 数据预加载器开发

**文件**: `core/advisor_v4/data_preloader.py`

**功能**:

- 利用聚宽3个并发连接并行下载数据
- 支持增量更新（只下载缺失数据）
- 数据本地缓存（Parquet格式，高效读写）
- 下载进度显示和断点续传

**关键实现**:

```python
class DataPreloader:
    def __init__(self, max_workers: int = 3, cache_dir: str = "data/cache"):
        self.max_workers = max_workers  # 聚宽最大3个连接
        self.cache_dir = Path(cache_dir)
        
    def preload_market_data(
        self,
        start_date: str,
        end_date: str,
        stock_pool: List[str] = None,  # None表示全A股
    ) -> Dict[str, Path]:
        """
        并行预加载市场数据
        - 日K线数据
        - 基本面数据（市值、ROE、净利润增长率）
        - 换手率数据
        """
        
    def preload_index_data(
        self,
        start_date: str,
        end_date: str,
        indices: List[str] = ["000300.XSHG", "000905.XSHG"]
    ) -> Dict[str, Path]:
        """预加载指数数据（用于基准对比）"""
```

## 测试场景

### 场景1: 长时间段回测

- 1年回测：2023-01-01 至 2023-12-31
- 2年回测：2022-01-01 至 2023-12-31
- 3年回测：2021-01-01 至 2023-12-31

### 场景2: 不同市场环境

- 牛市：2020-03-01 至 2021-02-28（疫情后反弹）
- 熊市：2021-12-01 至 2022-11-30（2022年下跌）
- 震荡市：2023-01-01 至 2023-12-31（震荡整理）

### 场景3: 参数敏感性

- 止损：-5%, -8%, -10%, -12%, -15%
- 止盈：20%, 30%, 40%, 50%
- 最大持股：5, 10, 15, 20

## 验证标准

### 稳定性指标

1. **收益稳定性**：不同时期收益率的方差<20%
2. **夏普比率**：所有时期夏普比率>1.0
3. **最大回撤**：所有时期最大回撤<30%
4. **胜率**：所有时期胜率>50%

### 市场适应性

1. **牛市表现**：年化收益>30%，夏普>1.5
2. **熊市表现**：最大回撤<20%，年化收益>0%
3. **震荡市表现**：年化收益>10%，夏普>0.8
