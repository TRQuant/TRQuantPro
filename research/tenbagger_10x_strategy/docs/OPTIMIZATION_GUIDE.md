## 🎯 标准回测指标

### 收益指标
- **总收益率**: (期末净值 - 期初净值) / 期初净值
- **年化收益率**: (1 + 总收益率)^(252/交易日数) - 1
- **超额收益**: 策略收益 - 基准收益

### 风险指标
- **波动率**: 日收益率标准差 × √252
- **最大回撤**: 净值从峰值到谷值的最大跌幅
- **回撤持续时间**: 最大回撤持续的天数

### 风险调整收益
- **夏普比率**: (年化收益 - 无风险利率) / 波动率
- **索提诺比率**: (年化收益 - 无风险利率) / 下行波动率
- **卡玛比率**: 年化收益 / 最大回撤

### 基准对比
- **Beta**: 策略收益与基准收益的协方差 / 基准收益的方差
- **Alpha**: 年化收益 - Beta × 基准年化收益
- **信息比率**: 超额收益 / 跟踪误差

### 交易统计
- **胜率**: 盈利交易数 / 总交易数
- **盈亏比**: 平均盈利 / 平均亏损
- **平均持仓天数**: 总持仓天数 / 交易次数

---

## 💰 交易成本

### 佣金设置
- **佣金率**: 万分之一 (0.0001)
- **印花税**: 千分之一 (0.001，仅卖出)
- **滑点**: 千分之一 (0.001)

### 成本计算
```python
买入成本 = 价格 × 数量 × (1 + 佣金率 + 滑点)
卖出收入 = 价格 × 数量 × (1 - 佣金率 - 印花税 - 滑点)
```

## 🎯 标准回测指标

### 收益指标
- **总收益率**: (期末净值 - 期初净值) / 期初净值
- **年化收益率**: (1 + 总收益率)^(252/交易日数) - 1
- **超额收益**: 策略收益 - 基准收益

### 风险指标
- **波动率**: 日收益率标准差 × √252
- **最大回撤**: 净值从峰值到谷值的最大跌幅
- **回撤持续时间**: 最大回撤持续的天数

### 风险调整收益
- **夏普比率**: (年化收益 - 无风险利率) / 波动率
- **索提诺比率**: (年化收益 - 无风险利率) / 下行波动率
- **卡玛比率**: 年化收益 / 最大回撤

### 基准对比
- **Beta**: 策略收益与基准收益的协方差 / 基准收益的方差
- **Alpha**: 年化收益 - Beta × 基准年化收益
- **信息比率**: 超额收益 / 跟踪误差

### 交易统计
- **胜率**: 盈利交易数 / 总交易数
- **盈亏比**: 平均盈利 / 平均亏损
- **平均持仓天数**: 总持仓天数 / 交易次数

## 💰 交易成本

### 佣金设置
- **佣金率**: 万分之一 (0.0001)
- **印花税**: 千分之一 (0.001，仅卖出)
- **滑点**: 千分之一 (0.001)

### 成本计算
```python
买入成本 = 价格 × 数量 × (1 + 佣金率 + 滑点)
卖出收入 = 价格 × 数量 × (1 - 佣金率 - 印花税 - 滑点)
```
