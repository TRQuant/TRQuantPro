## 三、策略组件详解

### 3.1 市场环境判断

**10种A股市场环境**：

| 环境 | 仓位上限 | 策略要点 |
|------|----------|----------|
| BULL_EARLY | 70% | 积极建仓，追逐主线 |
| BULL_MID | 80% | 最大仓位，持股为主 |
| BULL_LATE | 60% | 逐步减仓，锁定利润 |
| BEAR_PANIC | 10% | 空仓观望，不开新仓 |
| BEAR_GRINDING | 15% | 极小仓位，等待反转 |
| VOLATILE_UP | 50% | 中等仓位，顺势而为 |
| VOLATILE_DOWN | 25% | 减仓避险，等待机会 |
| VOLATILE_RANGE | 40% | 高抛低吸，波段操作 |
| RECOVERY | 60% | 逐步加仓，布局主线 |
| DISTRIBUTION | 30% | 减仓为主，回避风险 |

**检测方法**：
- 沪深300 MA20/MA60 趋势
- 20日动量
- 波动率指标

### 3.2 十倍股候选池筛选

**筛选条件**（L0硬过滤）：
```python
SCREEN_CRITERIA = {
    "market_cap": (20, 500),       # 市值20-500亿
    "profit_growth": ">15%",        # 利润增速
    "revenue_growth": ">10%",       # 营收增速
    "exclude_st": True,             # 排除ST
    "min_listing_days": 365,        # 上市满1年
    "stage": ["S0", "S1", "S2", "S3"],  # 排除成熟期
}
```

### 3.3 早期进入算法

**7维度评分（满分100分）**：

| 维度 | 权重 | 说明 |
|------|------|------|
| 阶段评分 | 25分 | S2最高25分，S1次之 |
| 增长加速 | 20分 | 利润增速环比提升 |
| 小市值加分 | 15分 | 30-100亿最高 |
| 市场主线 | 15分 | 处于热门主线 |
| 低关注度 | 10分 | 研报少、机构少 |
| 催化剂 | 10分 | 有明确催化事件 |
| 技术突破 | 5分 | 放量突破关键位 |

**入场阈值**：
- 牛市：>=60分
- 震荡/熊市：>=70分

### 3.4 阶段化持仓策略

| 阶段 | 最大仓位 | 止损 | 止盈 | 操作建议 |
|------|----------|------|------|----------|
| S0 观察期 | 3% | 25% | 无 | 小仓观察 |
| S1 验证期 | 8% | 20% | 50% | 逐步建仓 |
| S2 导入期 | 15% | 15% | 100% | ★重点买入★ |
| S3 放量期 | 12% | 12% | 50% | 持有减仓 |
| S4 加速期 | 8% | 10% | 30% | 逐步退出 |
| S5 成熟期 | 5% | 8% | 20% | 全部退出 |

### 3.5 止盈止损规则

**止盈**（分批止盈）：
- 翻倍(+100%)：卖出15%
- 3倍(+200%)：卖出30%
- 5倍(+400%)：卖出40%
- 10倍(+900%)：卖出50%（保留部分）

**止损**：
- 牛市：-15%
- 震荡市：-12%
- 熊市：-10%

**特殊规则**：
- 熊市逢高减仓：涨10%卖出50%
- 阶段成熟(S5)：全部退出
- 逻辑证伪：全部退出
