## 🧠 核心改进

### 1. 知识库整合
- `bear_market_exit_kb.py` - 熊市早期退出机制
- `mainline_rotation_kb.py` - 市场主线轮动识别
- `altdata_integration_kb.py` - 另类数据整合
- `ml_stage_predictor_kb.py` - ML阶段预测

### 2. 选股逻辑优化
```python
# 严格的基本面筛选（来自V8核心逻辑）
- 市值: 20-500亿（排除大盘股和微型股）
- 利润增速: >15%（成长性要求）
- 营收增速: >10%（业务扩张要求）
- 阶段: 排除S4成熟期和S5衰退期

# 使用TenbaggerIdentifier评分
- 综合评估ROE、毛利率、增速、PEG等
- 识别潜在十倍股特征
```

### 3. 调仓策略
```python
# 定期调仓而非每日交易
- 调仓周期: 60天（约2个月）
- 环境检测: 每5天检测一次市场环境
- 非调仓日: 只执行止盈止损
```

### 4. 市场环境感知
```python
# 简化三档策略
牛市(BULL_*):  仓位80%, 止损15%, 止盈50%
震荡(VOLATILE_*): 仓位30-60%, 止损10%, 止盈30%
熊市(BEAR_*): 仓位10-25%, 止损8%, 止盈25%
```

### 5. 熊市保护
```python
# 熊市环境过滤
BEAR_PANIC: 完全不买入
BEAR_GRINDING: 只选高成长(profit_growth>30%)且高得分(score>65)
VOLATILE_DOWN: 只选最优(score>60)
```
